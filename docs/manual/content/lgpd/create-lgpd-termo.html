Create Lgpd Termo

Função no sistema

Cadastra um novo registro em Create Lgpd Termo. Preencha os campos obrigatórios e salve; o registro passará a aparecer nas listagens e poderá receber permissões conforme o pacote.

Visão geral do módulo: consulte também o tópico Consentimentos LGPD (lgpd-consentimentos) para o fluxo completo da área.

Quem acessa: usuários com permissão CreateLgpdTermo.

O que significam os termos

LGPD
Lei Geral de Proteção de Dados: regras para tratar dados pessoais com base legal, segurança e direitos do titular.

Fluxo principal (passo a passo)

  1. Na listagem, clique em Cadastrar (ou acesse diretamente create-lgpd-termo).
  2. Preencha todos os campos obrigatórios marcados no formulário.
  3. Revise o impacto de status, vínculos e flags (ativo, público, padrão) antes de salvar.
  4. Confirme o cadastro; o sistema exibirá mensagem de sucesso ou erro de validação.
  5. Volte à listagem e verifique se o novo registro aparece com os filtros corretos.

Campos e parâmetros

O que cada campo afeta no sistema.

Campos do formulário Cada campo do formulário grava um atributo do registro; campos vazios podem impedir o salvamento.
Publicar no canal público Se marcado, o termo aparece em /lgpd/{slug} sem login. Use para Política de Privacidade etc. Não marque Termos de Uso do sistema.
Slug da URL Ex.: politica, termos. Reservados: requisicao, enviar, documento.
Status / Ativo Quando existir, registro inativo costuma sumir de seleções e do menu.

Problemas comuns

Não vejo o menu desta tela
Permissão CreateLgpdTermo ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
Pressione F1 nesta tela para reabrir esta ajuda contextual
