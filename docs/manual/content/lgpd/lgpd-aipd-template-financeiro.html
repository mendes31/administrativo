Template AIPD - Setor Financeiro

Função no sistema

Tela Template AIPD - Setor Financeiro do módulo LGPD. Use o fluxo e os campos descritos abaixo para operar o recurso.

Visão geral do módulo: consulte também o tópico AIPD / RIPD (lgpd-aipd) para o fluxo completo da área.

Quem acessa: usuários com permissão LgpdAipdTemplateFinanceiro.

Fluxo principal (passo a passo)

  1. Acesse Template AIPD - Setor Financeiro pelo menu LGPD.
  2. Use os filtros e ações da tela conforme sua permissão.
  3. Preencha filtros ou parâmetros antes de executar.
  4. Pressione F1 para contextualizar a ajuda.

Problemas comuns

Não vejo o menu desta tela
Permissão LgpdAipdTemplateFinanceiro ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
