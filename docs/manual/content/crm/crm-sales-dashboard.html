Dashboard de Vendas SAP (CRM)

Função no sistema

Painel comercial com faturamento líquido SAP Business One (faturas OINV e devoluções ORIN), KPIs, gráficos Chart.js e filtros cruzados. Os dados vêm de um cache MySQL sincronizado a partir do HANA (não consulta o SAP a cada filtro). É independente do Dashboard CRM de pipeline/oportunidades.

O que significam os termos

Faturamento líquido
Soma de linhas de fatura menos devoluções (valores sinalizados) no período filtrado.
AnoMes
Competência mensal do documento (YYYY-MM), usada na evolução e no isolamento de mês.
Cache MySQL
Tabela crm_sales_fact_daily com fatos diários agregados por cliente e dimensões comerciais. O painel lê só este cache.
VIEW VW_CRM_VENDAS_LINHA
Objeto no HANA usado na sincronização (não no carregamento do painel). Sem ela, o sync usa CTE com filtro de data — mais lento na carga inicial.
Atualizar agora (incremental)
Botão que dispara sync incremental (HANA → MySQL, overlap de ~3 dias). A carga completa (36 meses) é só via CLI --full.
Sync no 1º acesso do dia
Ao abrir o painel pela primeira vez no dia, o sistema sincroniza o incremento automaticamente (com lock para não duplicar). Demais acessos/filtros no mesmo dia leem só o cache.
Cross-filter
Clique em barra, fatia ou ponto aplica filtro ao painel inteiro; chips permitem remover cada filtro.

Quem acessa: usuários com permissão CrmSalesDashboard (dados via CrmSalesDashboardData; sync via CrmSalesDashboardSync). A migration copia ACL a partir de CrmDashboard/CrmSalesDashboard.

Fluxo principal

  1. Na primeira vez, execute a migration e o sync completo: vendor/bin/phinx migrate e php scripts/sync_crm_sales_sap.php --full.
  2. Acesse CRM → Dashboard de Vendas SAP.
  3. Escolha o período (mês atual/anterior, últimos 3–36 meses, ano atual YTD, ano anterior ou personalizado com data início/fim).
  4. No personalizado, preencha as datas e clique em Atualizar.
  5. Opcionalmente filtre por vendedor, grupo de cliente ou região na barra de ferramentas.
  6. Clique em gráficos (evolução, grupo, vendedor, região, grupo de item) para refinar; use chips ou Limpar tudo.
  7. Para forçar atualização no meio do dia, use Atualizar agora (incremental). O 1º acesso do dia já sincroniza sozinho.
  8. Confira no rodapé/meta a data da última sincronização e a fonte do sync (VIEW ou CTE).

Campos e parâmetros

Período Presets: mês atual, mês anterior, últimos 3/6/12/24/36 meses, ano atual (YTD), ano anterior; ou Personalizado com data início e data fim (máx. 36 meses). Padrão: últimos 12 meses.
Data início / Data fim Visíveis só no período personalizado; aplicadas ao clicar em Atualizar (date_from/date_to na API).
Vendedor Nome do vendedor SAP (OSLP.SlpName).
Grupo de cliente Grupo do PN (OCRG.GroupName).
Região Preferência pelo território SAP (OTER.descript); se vazio no cadastro do PN, usa a UF (OCRD.State1). Sem ambos: “Sem região”.
KPIs Faturamento líquido, devoluções, taxa de devolução e ticket médio por cliente ativo.
API dados Endpoint crm-sales-dashboard-data agrega só no MySQL (resposta rápida ao trocar filtros).
API sync Endpoint crm-sales-dashboard-sync — somente incremental na web. Full sync apenas via CLI.
CLI / cron php scripts/sync_crm_sales_sap.php (incremental), --full (36 meses). Cron opcional se não quiser depender do 1º acesso do dia.

Problemas comuns

Não vejo o menu
Execute vendor/bin/phinx migrate e confirme permissão CrmSalesDashboard no nível de acesso.
Cache vazio / aviso de sincronização
Rode php scripts/sync_crm_sales_sap.php --full uma vez. Depois o 1º acesso do dia e o botão incremental mantêm o cache.
Erro da API SAP / timeout no sync
Confirme a Configuração SAP API. Em produção, crie a VIEW VW_CRM_VENDAS_LINHA (docs/sql/hana/VW_CRM_VENDAS_LINHA.sql) e conceda SELECT — o CTE fallback deixa o --full bem mais lento.
Painel rápido, mas números “atrasados”
Esperado: o painel lê MySQL. Use Atualizar agora (incremental) ou abra o painel (1º acesso do dia). Cancelamentos/ajustes recentes entram no overlap de 3 dias.
Barras com valor muito alto (ex.: TERCEIROS / SP)
A escala é limitada em silêncio para comparar os demais; o valor real aparece no rótulo/tooltip (marcador ▸). Os gráficos de barras mostram cerca de 10 itens e têm rolagem para o restante.
Gráficos vazios
Sem movimentos no período, filtros muito restritivos ou cache ainda não cobre o intervalo. Use Limpar tudo, amplie o período ou rode sync --full.
Confundi com Dashboard CRM
O Dashboard CRM trata pipeline/oportunidades internas; este painel usa vendas reais do SAP via cache.
