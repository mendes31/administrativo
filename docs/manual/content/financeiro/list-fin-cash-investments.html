Aplicações Financeiras

Função no sistema

Registra no próprio sistema as movimentações de aplicação financeira (aplicação, resgate e rendimento) que o SAP não cobre no dia a dia. Hoje o ERP costuma receber só o rendimento mensal; aplicações e resgates entram aqui e alimentam o saldo de aplicações do Dashboard de Fluxo de Caixa SAP, no mesmo recorte por banco da planilha de tesouraria.

O que significam os termos

Aplicação
Saída de recurso da conta corrente para um investimento. Aumenta o saldo de aplicações.
Resgate
Retorno do investimento para o caixa/banco. Diminui o saldo de aplicações.
Rendimento
Juros/atualização creditados na aplicação, sem necessariamente movimentar a conta corrente no mesmo valor.
Categoria padrão
Aplicações livres (equivalente à tabela principal da planilha).
Categoria garantia
Aplicações vinculadas a garantia (linhas “banco (garantia)” da planilha).
Banco / conta
Rótulo livre (ex.: Banco ABC, Safra (garantia)) usado para agrupar a visão mensal.

Quem acessa: usuários com permissão ListFinCashInvestments. Cadastrar exige CreateFinCashInvestment; editar UpdateFinCashInvestment; excluir DeleteFinCashInvestment.

Fluxo principal

  1. Acesse Financeiro → Aplicações Financeiras (ou o atalho no dashboard).
  2. Clique em Cadastrar.
  3. Escolha o tipo (aplicação, resgate ou rendimento), a categoria (padrão ou garantia), a data, o banco e o valor.
  4. Opcionalmente vincule a uma conta SAP classificada como aplicação.
  5. Salve. O saldo mensal do banco é o acumulado de aplicações + rendimentos − resgates até o fim de cada mês.
  6. Confira o resultado na aba Aplicações do Dashboard Fluxo de Caixa SAP.

Campos e parâmetros

Tipo Aplicação, resgate ou rendimento.
Categoria Padrão ou garantia — separa as duas tabelas mensais.
Data Data do lançamento, usada no saldo acumulado até o mês.
Banco / conta Nome de agrupamento; sugestões vêm de lançamentos anteriores.
Valor Em reais (aceita 1234,56 ou 1.234,56).
Conta SAP Vínculo opcional com a parametrização de contas financeiras.
Descrição Observação livre (número de aplicação, competência do rendimento, etc.).

Problemas comuns

Saldo do dashboard não mudou
Confirme a data do lançamento no mês/ano filtrado e se o status está ativo. Recarregue o dashboard (não depende do sync SAP).
Banco duplicado na tabela mensal
Use exatamente o mesmo rótulo (maiúsculas/acentos contam). Prefira as sugestões do campo Banco.
Rendimento já lançado no SAP
Se a conta SAP já está como Aplicação, o saldo contábil entra pelo sync. Evite lançar o mesmo rendimento localmente para não duplicar.
Não vejo o botão Cadastrar
Falta a permissão CreateFinCashInvestment no nível de acesso.
