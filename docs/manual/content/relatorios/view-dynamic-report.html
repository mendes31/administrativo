Visualizar Relatório Dinâmico

Função no sistema

Exibe os dados de um registro de Visualizar Relatório Dinâmico em modo somente leitura, com atalhos para editar ou excluir quando permitido.

Visão geral do módulo: consulte também o tópico Relatórios dinâmicos (rel-dinamicos) para o fluxo completo da área.

Quem acessa: usuários com permissão ViewDynamicReport.

Fluxo principal (passo a passo)

  1. Na listagem, clique em Visualizar no registro desejado.
  2. Revise ID, datas de cadastro/edição e observações.
  3. Use os botões do cabeçalho para ir à listagem, editar ou consultar log de alterações.

Campos e parâmetros

O que cada campo afeta no sistema.

Dados exibidos Resultado da consulta SQL; a tela formata pelo tipo do valor (data, mês/ano, moeda), sem exigir alias especial.
Data Valores ISO (2026-08-01T00:00:00) aparecem como 01/08/2026. Se a coluna inteira for dia 1 à meia-noite (agregação mensal da API SAP), aparece 08/2026.
Moeda Números com 1 ou 2 casas decimais aparecem como R$ 1.234,56. Inteiros não viram moeda (código de item, quantidade, DocEntry).

Problemas comuns

Não vejo o menu desta tela
Permissão ViewDynamicReport ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Valor não aparece em R$ ou data continua ISO
Atualize a página (Ctrl+F5). A formatação usa o tipo do dado na coluna, não o nome do alias. Inteiros não são moeda; Excel continua com o número cru.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
Pressione F1 nesta tela para reabrir esta ajuda contextual
