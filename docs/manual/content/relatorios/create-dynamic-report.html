Create Dynamic Report

Função no sistema

Cadastra um novo registro em Create Dynamic Report. Preencha os campos obrigatórios e salve; o registro passará a aparecer nas listagens e poderá receber permissões conforme o pacote.

Visão geral do módulo: consulte também o tópico Relatórios dinâmicos (rel-dinamicos) para o fluxo completo da área.

Quem acessa: usuários com permissão CreateDynamicReport.

Fluxo principal (passo a passo)

  1. Na listagem, clique em Cadastrar (ou acesse diretamente create-dynamic-report).
  2. Preencha todos os campos obrigatórios marcados no formulário.
  3. Revise o impacto de status, vínculos e flags (ativo, público, padrão) antes de salvar.
  4. Confirme o cadastro; o sistema exibirá mensagem de sucesso ou erro de validação.
  5. Volte à listagem e verifique se o novo registro aparece com os filtros corretos.

Campos e parâmetros

O que cada campo afeta no sistema.

Campos do formulário Cada campo do formulário grava um atributo do registro; campos vazios podem impedir o salvamento.
Status / Ativo Quando existir, registro inativo costuma sumir de seleções e do menu.
Disponível no chat Se marcado, o Assistente MCP (modo local:internal) pode executar este relatório pela tool report.run, respeitando a ACL (público / partilha / criador).
Nome da tool / descrição / exemplos Identificador estável, texto para a IA e frases de exemplo (uma por linha) usadas para reconhecer a pergunta no chat.

Problemas comuns

Não vejo o menu desta tela
Permissão CreateDynamicReport ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
Pressione F1 nesta tela para reabrir esta ajuda contextual
