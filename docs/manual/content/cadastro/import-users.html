Importar Usuários

Função no sistema

Importa ou atualiza colaboradores via Excel (.xlsx) ou CSV. Há dois modos: mapeamento de colunas e template oficial com cabeçalhos fixos.

Visão geral do módulo: consulte também o tópico Cadastro de usuários (cad-usuarios) para o fluxo completo da área.

Quem acessa: usuários com permissão ImportUsers.

Onde fica: menu Cadastro → Usuários → Importar Usuários, ou o botão Importar na listagem de usuários.

Para carga de colaboradores, departamentos e cargos com simulação e chave por CPF/nome, use também a Central de Importações (import-center) em Administração. Esta tela clássica permanece para formações e o template oficial.

Fluxo — mapeamento de colunas (recomendado)

Funciona em dois passos:

  1. Monte a planilha no Excel (uma coluna por campo). Prefira salvar como .xlsx.
  2. Escolha o arquivo e, em O que importar, selecione dados do usuário, somente formações ou ambos.
  3. Deixe Mapeamento de colunas marcado e clique em Abrir mapeamento.
  4. Na tela seguinte, para cada campo do sistema escolha a coluna do arquivo (ou “não importar”). Defina a chave única (CPF, usuário/login ou ID).
  5. Escolha o método: só atualizar, ou criar e atualizar.
  6. Clique em Importar com mapeamento e revise o resumo.

Fluxo — template oficial

  1. Baixe o template, preencha e importe no modo Template oficial.
  2. Antes de enviar, escolha o escopo em O que importar. A seleção também vale para o template oficial.
  3. A chave nesse modo é a coluna username.
  4. Para várias formações do mesmo usuário, repita o username em linhas diferentes e preencha uma formação em cada linha.

Campos e parâmetros

O que cada campo afeta no sistema.

Chave única Localiza o registro: CPF, username ou ID. Sem chave válida a linha é ignorada ou gera erro.
Somente dados do usuário Processa apenas campos exclusivos do cadastro e ignora todas as colunas formacao_*. É a opção padrão e mais segura para planilhas cadastrais.
Somente formações Exige um usuário já existente, não cria usuários e não altera nome, contatos, endereço, cargo ou demais dados exclusivos, mesmo que essas colunas estejam no arquivo.
Dados do usuário + formações Processa os dois grupos. Cada linha contém no máximo uma formação; repita a chave para registrar várias.
Mapeamento Só os campos associados a uma coluna são gravados; o restante do cadastro permanece. Cabeçalhos iguais aos nomes dos campos (ex.: username, matricula) são pré-selecionados. Cada coluna do arquivo só pode ser usada em um campo.
Resultado Após importar, o resumo mostra totais e uma tabela por linha da planilha (linha 1 = cabeçalho). “Atualizado” significa que o usuário já existia e os campos mapeados foram gravados.
escolaridade / raca Aceitam slug ou rótulo do cadastro.
Endereço e matrícula Colunas opcionais: CEP, logradouro, número, complemento, bairro, município, UF, matrícula, e-mail pessoal.
Formações Colunas: formacao_id, formacao_acao, formacao_tipo, formacao_curso, formacao_instituicao, formacao_situacao, datas, carga horária e observações. Uma linha representa uma formação.
Criar/atualizar formação Use formacao_acao=salvar. Sem ID, o sistema evita duplicidade pela combinação tipo + curso + instituição. Com formacao_id, atualiza exatamente aquele registro.
Excluir formação Use formacao_acao=excluir e informe obrigatoriamente o formacao_id. O ID deve pertencer ao usuário indicado na linha.
Valores aceitos Tipos: curso_livre, profissionalizante, tecnico, graduacao, pos_graduacao, mba, mestrado, doutorado, pos_doutorado ou outro. Situações: cursando, concluido, trancado ou interrompido. Rótulos em português também são aceitos.
Comprovantes Arquivos não são importados pela planilha. Depois da importação, anexe diploma ou certificado na aba Formações da edição do usuário.

Problemas comuns

Não vejo o menu desta tela
Permissão ImportUsers ausente no seu nível de acesso.
Só aparece uma coluna no mapeamento
Evite CSV “quebrado”: no Excel use Salvar como → Pasta de Trabalho (.xlsx) e envie o .xlsx. Se usar CSV, confira se há várias colunas e o separador é ; ou ,.
Chave não encontrada
No modo “somente atualizar” e no escopo “Somente formações”, linhas sem usuário correspondente são ignoradas. Confira CPF/username.
Campos desapareceram do mapeamento
A tabela mostra apenas os campos compatíveis com o escopo selecionado. Escolha “Dados do usuário + formações” para visualizar ambos.
Campo mapeado duas vezes
Cada coluna do arquivo só pode ser associada a um campo do sistema.
Excel não sobe
Formatos aceitos tanto no mapeamento quanto no template oficial: .xlsx, .xls e .csv.
A mesma formação foi importada novamente
Informe o formacao_id exportado para atualização explícita. Sem ID, mantenha idênticos tipo, curso e instituição para o sistema reconhecer o registro existente.
Não consigo excluir uma formação
A exclusão exige formacao_acao=excluir e um formacao_id pertencente ao usuário da linha.
