Listar Usuários

É a área operacional do RH para localizar colaboradores, aplicar filtros, abrir cadastros, importar atualizações em lote e exportar informações cadastrais e formações.

Visão geral do módulo: consulte também o tópico Cadastro de usuários (cad-usuarios) para o fluxo completo da área.

Quem acessa: usuários com permissão ListUsers.

Fluxo principal (passo a passo)

  1. Acesse o menu Cadastro e abra Listar Usuários.
  2. Use os filtros no topo para restringir por nome, login, departamento, cargo, turno, status, bloqueio, desligamento, sexo, filhos ou período.
  3. Ajuste Mostrar N registros se precisar ver mais linhas por página.
  4. Clique em Visualizar, Editar ou Cadastrar conforme sua permissão.
  5. Para operação em lote, use Importar; para conferência externa, exporte Excel ou PDF. Os filtros ativos também limitam a exportação.
  6. Pressione F1 nesta tela para reabrir esta ajuda contextual.

Campos e parâmetros

O que cada campo afeta no sistema.

Filtros de busca Restringem a grade e as exportações; não alteram cadastros. O filtro de período pode considerar admissão, desligamento ou atualização de cargo.
Mostrar N registros Controla paginação (10, 20, 50 ou 100 por página).
Ações (Visualizar / Editar / Apagar) Dependem das permissões do seu nível de acesso além da listagem.
Exportar Excel A aba Usuários inclui todos os campos cadastrais, ordenados como na tela: Usuário, Dados Pessoais, Endereço, Dados Contratuais e resumo de Formações. Senhas não são exportadas por segurança. A aba Formações traz um registro por curso, incluindo o ID necessário para futuras atualizações por importação.
Exportar PDF Após a lista de usuários, apresenta uma seção detalhada de formações dos colaboradores selecionados pelos filtros.

Problemas comuns

Não vejo o menu desta tela
Permissão ListUsers ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
Exportação veio com menos pessoas
Os filtros da listagem permanecem ativos na sessão e são aplicados ao Excel/PDF. Limpe os filtros e gere novamente.
A aba Formações do Excel está vazia
Somente formações cadastradas na aba Formações do usuário aparecem no detalhamento; o campo geral Escolaridade não cria uma formação automaticamente.
