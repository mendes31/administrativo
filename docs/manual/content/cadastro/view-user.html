Visualizar Usuário

Função no sistema

Centraliza a conferência do colaborador em abas alinhadas à edição: conta, dados pessoais, endereço, vínculo, formações, acessos TI, histórico e permissões do Portal. A tela é predominantemente somente leitura; alterações usam os atalhos autorizados.

Visão geral do módulo: consulte também o tópico Cadastro de usuários (cad-usuarios) para o fluxo completo da área.

Quem acessa: usuários com permissão ViewUser.

Fluxo principal (passo a passo)

  1. Na listagem, clique em Visualizar no registro desejado.
  2. Use o resumo no topo (foto, status, departamento, cargo) para conferência rápida.
  3. Navegue pelas abas Usuário, Dados Pessoais, Endereço, Dados Contratuais, Formações, Acessos, Histórico e Permissões. No celular as abas são as mesmas do desktop, em uma faixa que rola na horizontal quando não cabem na tela (arraste a faixa para o lado; a aba atual já entra visível); listas (formações, acessos TI, histórico) aparecem em cartões empilhados. Em Permissões só aparecem os níveis já atribuídos (somente leitura).
  4. Em Formações, baixe comprovantes quando houver anexo.
  5. Use Editar para abrir a mesma aba na edição; no celular, Mais abre um painel logo abaixo dos botões com senha, imagem, SST, log e apagar.

Campos e parâmetros

O que cada área mostra.

Resumo Identidade, status, bloqueio, super usuário, e-mail, departamento, cargo, empresa e tempo de casa.
Aba Usuário Conta no Portal, departamento, cargo, supervisor, turno e flags de senha/login.
Dados Pessoais / Endereço / Contratuais Mesma organização da edição, em modo leitura.
Formações Lista tipo, curso, instituição, situação, período, carga horária e comprovante (tabela no desktop; cartões no celular).
Acessos Mapa TI de sistemas/equipamentos (TiAcessosCreate / TiAcessosRevoke). No celular, cada liberação vira um cartão com login, situação e local. Não confundir com ACL de páginas.
Histórico Admissões, desligamentos, duração e classificação de impacto (cartões no celular).
Permissões Lista somente leitura dos níveis ACL atribuídos ao colaborador. Para alterar, use Editar → aba Permissões (UpdateUserAccessLevels). Super usuário indica acesso total sem pacotes.

Problemas comuns

Não vejo o menu desta tela
Permissão ViewUser ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (editar, excluir, permissões). Inclua a página filha no pacote.
Não vejo a aba Permissões
A aba aparece na visualização para quem tem ViewUser. Para editar os níveis, é necessária UpdateUserAccessLevels na tela de edição.
Comprovante não baixa
Confirme se o arquivo foi anexado e se você está autenticado com acesso à visualização do cadastro.
