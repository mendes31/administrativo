Editar Senha do Usuário

Função no sistema

Permite que um administrador defina uma nova senha para outro usuário, opcionalmente avise por e-mail ou WhatsApp e, no fluxo de desbloqueio, libere a conta na hora.

Quem acessa: usuários com permissão UpdatePasswordUser. O atalho fica em Visualizar Usuário (ViewUser).

Fluxo principal

  1. Abra o cadastro do colaborador e clique em Editar Senha.
  2. Informe a senha e a confirmação, ou marque Gerar senha automática para usar a data de nascimento no formato ddmmaaaa.
  3. Se a pessoa deve trocar a senha no próximo acesso, marque Modificar senha no próximo logon.
  4. Para avisar, marque e-mail e/ou WhatsApp e escolha o tipo da mensagem.
  5. Clique em Salvar. A tela volta para a visualização do usuário.

Campos e parâmetros

Senha / Confirmar a Senha Nova senha. Espaços são removidos. Quando a geração automática está marcada, o que foi digitado é ignorado.
Gerar senha automática Monta a senha provisória com a data de nascimento (ddmmaaaa). Exige data de nascimento no cadastro.
Modificar senha no próximo logon Depois do login, o sistema exige que o usuário defina outra senha.
Notificar usuário Envia a senha por e-mail corporativo e/ou WhatsApp (celular do cadastro). Sem marcação, a senha é gravada e ninguém é avisado.
Tipo de mensagem — Senha provisória / desbloqueio Texto de conta desbloqueada. Ao salvar, se o usuário estiver bloqueado, a conta é liberada: Bloqueado passa a Não e as tentativas de login são zeradas. Sem isso o login continua recusando a conta mesmo com a senha nova.
Tipo de mensagem — Boas-vindas Texto de primeiro acesso. Não altera o bloqueio.

Problemas comuns

A senha foi enviada e o usuário continua Bloqueado
O tipo precisa ser Senha provisória / desbloqueio. Boas-vindas só troca a senha. Se a mensagem avisar que a conta continuou bloqueada, abra Editar e deixe o switch em Não bloqueado.
O usuário não consegue entrar depois do desbloqueio
Confira se o status está Ativo. Conta inativa também é recusada no login, mesmo desbloqueada.
A geração automática não preenche a senha
O cadastro precisa ter data de nascimento válida.
O aviso não chegou
Confira e-mail corporativo ou celular e se a opção correspondente estava marcada. A senha já foi gravada mesmo se o envio falhar.
