Liberar Permissões

Função no sistema

Tela onde você define, para um nível de acesso específico, quais páginas do sistema ficam autorizadas ou revogadas. As páginas são exibidas agrupadas por grupo de páginas (ACL), com um interruptor por página e ações rápidas para autorizar ou revogar um grupo inteiro.

Visão geral do módulo: consulte também o tópico Níveis de acesso (cad-niveis-acesso) e Permissões - visão geral (adm-permissoes).

Quem acessa: usuários com permissão ListAccessLevelsPermissions.

Grupo Canal de Denúncias: por sigilo e para não gerar dúvidas quanto ao anonimato do canal, as páginas do grupo Canal de Denúncias só aparecem nesta matriz para Super Administrador ou Super usuário. Demais usuários não visualizam esse grupo e não conseguem conceder/remover essas páginas - mesmo que enviem o formulário, as concessões atuais do canal são preservadas. O acesso ao módulo é dado pelos níveis Canal de Denúncias - Operador/Administrador (o Operador também é herdado automaticamente ao vincular a pessoa a um comitê).

O que significam os termos

Grupo de páginas
Pasta da matriz ACL (adms_groups_pages). Organiza a tela de permissões; não é o menu lateral do sistema.
Autorizar / Revogar grupo
Liga ou desliga de uma vez todas as páginas daquele grupo para o nível em edição.

Fluxo principal (passo a passo)

  1. Acesse Cadastro → Níveis de Acesso e clique em Permissões no nível desejado.
  2. Confira o badge com o nome do nível no topo da tela.
  3. Use a busca Buscar por grupo (ex.: digite Gestão de Pessoas, Estoque -, CRM -, SST - ou LGPD -) ou Expandir Todos / Colapsar Todos.
  4. Ative ou desative o interruptor de cada página, ou use Autorizar Grupo / Revogar Grupo no recorte desejado.
  5. Clique em Salvar para gravar as permissões do nível.
  6. Se necessário, use Exportar PDF para gerar o relatório de permissões do nível.
  7. Peça ao usuário afetado para sair e entrar novamente (recarrega o menu).
  8. Pressione F1 nesta tela para reabrir esta ajuda contextual.

Grupos fatiados (Gestão de Pessoas, SST, LGPD, Estoque, CRM)

Os antigos mega-grupos foram cindidos. Na matriz você verá, por exemplo:

  • Gestão de Pessoas - Talentos (ATS); Portal / Solicitações; Desempenho e Carreira; Organização / Políticas
  • SST - Medicina / ASO / Exames; EPI; Equipamentos / Vistoria; Treinamentos / GHE / PPP; Cadastros e vínculos; Acidentes / Afastamentos; Dashboard / Relatórios
  • LGPD - Taxonomia; Inventário / ROPA / Mapping; AIPD; TIA; RIPD; Consentimentos; Titulares; Dashboard / Termos / Legal
  • Estoque - Itens e movimentações; Custeio
  • CRM - Operação; Integrações e configurações

Os grupos legados Gestão de Pessoas, Segurança e Medicina, LGPD, Estoque e CRM (sem sufixo de subárea) podem aparecer vazios após a migration. O menu lateral não muda com essa cisão; permissões já concedidas por página são preservadas. O prefixo completo Gestão de Pessoas evita confusão com outros módulos (ex.: Gestão de Projetos).

Campos e parâmetros

O que cada elemento afeta no sistema.

Badge do nível Identifica qual nível de acesso está sendo editado. A navegação de volta à listagem fica no breadcrumb Níveis de Acesso.
Interruptor da página (Autorizada/Revogada) Concede (1) ou remove (0) o acesso do nível àquela página. Páginas privadas exigem liberação manual; públicas já ficam acessíveis pela rota.
Autorizar Grupo / Revogar Grupo Marca ou desmarca todas as páginas daquele grupo (ex.: só Gestão de Pessoas - Talentos (ATS)). Prefira o subgrupo certo em vez de liberar um domínio inteiro de uma vez.
Buscar por grupo Filtra os módulos exibidos; não altera dados, apenas a exibição.
Exportar PDF Gera um relatório com as páginas autorizadas do nível de acesso.

Regras importantes

  • O nível Super Administrador tem acesso total; a matriz dele é somente leitura e não pode ser gravada.
  • O grupo Canal de Denúncias só é gerenciável por Super Administrador ou Super usuário (ver nota acima).
  • Páginas novas não públicas / não padrão nascem sem permissão; liberação é nesta matriz (exceto Super Administrador / Super usuário).

Problemas comuns

Não vejo o menu desta tela
Permissão ListAccessLevelsPermissions ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no nível.
Não encontro “Gestão de Pessoas” / “Estoque” / “CRM” cheios
Após a cisão, busque pelos prefixos Gestão de Pessoas -, Estoque -, CRM -, SST - ou LGPD -. Os nomes antigos sem sufixo ficam vazios ou residuais.
Autorizar Grupo não liberou o menu inteiro de SST/RH
É esperado: cada subgrupo cobre só um recorte. Autorize os subgrupos necessários (ex.: EPI e Equipamentos) ou página a página.
Não encontro o grupo Canal de Denúncias na matriz
É intencional: esse grupo só aparece para Super Administrador ou Super usuário. Para dar acesso ao módulo, atribua os níveis Canal de Denúncias - Operador/Administrador ao usuário (ou vincule a pessoa a um comitê, que concede o Operador automaticamente).
