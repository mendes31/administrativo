Liberar Permissões

Tela onde você define, para um nível de acesso específico, quais páginas do sistema ficam autorizadas ou revogadas. As páginas são exibidas agrupadas por módulo, com um interruptor por página e ações rápidas para autorizar ou revogar um grupo inteiro.

Visão geral do módulo: consulte também o tópico Níveis de acesso (cad-niveis-acesso) para o fluxo completo da área.

Quem acessa: usuários com permissão ListAccessLevelsPermissions.

Grupo Canal de Denúncias: por sigilo e para não gerar dúvidas quanto ao anonimato do canal, as páginas do grupo Canal de Denúncias só aparecem nesta matriz para Super Administrador ou Super usuário. Demais usuários não visualizam esse grupo e não conseguem conceder/remover essas páginas — mesmo que enviem o formulário, as concessões atuais do canal são preservadas. O acesso ao módulo é dado pelos níveis Canal de Denúncias — Operador/Administrador (o Operador também é herdado automaticamente ao vincular a pessoa a um comitê).

Fluxo principal (passo a passo)

  1. Acesse Cadastro → Níveis de Acesso e clique em Permissões no nível desejado.
  2. Use a busca Buscar por grupo ou os botões Expandir Todos / Colapsar Todos para navegar entre os módulos.
  3. Ative ou desative o interruptor de cada página, ou use Autorizar Grupo / Revogar Grupo para aplicar a todas as páginas do módulo de uma vez.
  4. Clique em Salvar para gravar as permissões do nível.
  5. Se necessário, use Exportar PDF para gerar o relatório de permissões do nível.
  6. Pressione F1 nesta tela para reabrir esta ajuda contextual.

Campos e parâmetros

O que cada elemento afeta no sistema.

Interruptor da página (Autorizada/Revogada) Concede (1) ou remove (0) o acesso do nível àquela página. Páginas privadas exigem liberação manual; públicas já ficam acessíveis pela rota.
Autorizar Grupo / Revogar Grupo Marca ou desmarca de uma vez todas as páginas do módulo exibido.
Buscar por grupo Filtra os módulos exibidos; não altera dados, apenas a exibição.
Exportar PDF Gera um relatório com as páginas autorizadas do nível de acesso.

Regras importantes

  • O nível Super Administrador tem acesso total; a matriz dele é somente leitura e não pode ser gravada.
  • O grupo Canal de Denúncias só é gerenciável por Super Administrador ou Super usuário (ver nota acima).

Problemas comuns

Não vejo o menu desta tela
Permissão ListAccessLevelsPermissions ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
Não encontro o grupo Canal de Denúncias na matriz
É intencional: esse grupo só aparece para Super Administrador ou Super usuário. Para dar acesso ao módulo, atribua os níveis Canal de Denúncias — Operador/Administrador ao usuário (ou vincule a pessoa a um comitê, que concede o Operador automaticamente).
