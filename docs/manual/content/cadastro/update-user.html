Editar Usuário

Função no sistema

Altera um registro existente de Editar Usuário. Mudanças em campos de status ou vínculos podem afetar menu, permissões ou integrações.

Visão geral do módulo: consulte também o tópico Cadastro de usuários (cad-usuarios) para o fluxo completo da área.

Quem acessa: usuários com permissão UpdateUser.

Fluxo principal (passo a passo)

  1. Na listagem, localize o registro e clique em Editar.
  2. Use as abas Usuário, Dados Pessoais, Endereço, Dados Contratuais e Formações para alterar só o necessário.
  3. Em Formações, clique em Adicionar formação, informe tipo, curso e situação; instituição, datas, carga horária, observações e comprovante são opcionais.
  4. Salve as alterações e confira a mensagem de retorno.
  5. Teste com um usuário do perfil impactado (logout/login) se mudou permissões ou status.

Campos e parâmetros

O que cada campo afeta no sistema.

Abas do formulário Usuário (conta/acesso), Dados Pessoais, Endereço, Dados Contratuais (empresa, matrícula, vínculo e desligamento) e Formações.
Aba ativa A URL acompanha a aba selecionada. Ao atualizar o navegador, a edição permanece na mesma aba.
Formações Aceita vários cursos, graduações, pós-graduações, MBAs, mestrados e doutorados para o mesmo usuário. O campo geral Escolaridade continua representando o maior grau de instrução.
Comprovante Opcional por formação. Formatos: PDF, JPG, PNG, WEBP, DOC ou DOCX, até 10 MB. O arquivo é privado e baixado somente por usuário autenticado com acesso à visualização do cadastro.
Excluir ou substituir Marque Excluir para remover toda a formação. Para trocar o comprovante, selecione outro arquivo; para retirar apenas o arquivo, marque Remover comprovante.
E-mail pessoal e endereço Opcionais. Endereço: priorize busca por CEP (ViaCEP), como no CRM; e-mail pessoal é distinto do e-mail corporativo de login.
Campos editáveis Somente campos exibidos podem ser alterados; IDs e auditoria são somente leitura.
Integração LNT Alterações de cargo ou desligamento (inativação ou data de desligamento) geram evento para a equipe de treinamentos. Gere o LNT do colaborador em Eventos LNT (RH) antes de arquivar documentação física.

Problemas comuns

Não vejo o menu desta tela
Permissão UpdateUser ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
Comprovante não foi aceito
Confira o formato e o limite de 10 MB. Renomear um arquivo para outra extensão não altera o tipo real e será rejeitado.
Não encontro a aba Formações
A aba está disponível no cadastro (permissão CreateUser) e na edição (permissão UpdateUser) do usuário.
