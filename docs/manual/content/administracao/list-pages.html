Listar Páginas

Lista todas as páginas registradas no ACL: cada entrada mapeia um controller PHP a uma URL e controla aparecimento no menu e na matriz de permissões.

Visão geral do módulo: consulte também o tópico Permissões — visão geral (adm-permissoes) para o fluxo completo da área.

Quem acessa: ListPages; cadastro com CreatePage, edição UpdatePage.

Fluxo principal (passo a passo)

  1. Acesse Administração → Páginas → Páginas.
  2. Use filtros: ID, Nome, Controller, Grupo, Status, Pública, Padrão.
  3. Localize a tela desejada e edite para corrigir slug, pacote ou status.
  4. Cadastre novas páginas após criar controllers no código-fonte.
  5. Inclua a página no pacote do perfil e marque na matriz do nível de acesso.

Impacto de Status e Pública

Inativa: página não é oferecida em novas configurações. Pública: ignora autenticação. Padrão: facilita bootstrap de novos perfis, mas não remove permissões já dadas.

Campos e parâmetros

O que cada campo afeta no sistema.

ID Identificador interno da página no banco.
Nome Rótulo na matriz de permissões.
Controller (filtro) Busca pela classe PHP (ex.: ListUsers).
Grupo (filtro) Restringe às páginas de um grupo de páginas.
Status Ativa (1) ou Inativa (0) — inativa some do menu e da matriz ativa.
Pública Sim = rota acessível sem login (login, recuperar senha, etc.).
Padrão Sim = novos níveis de acesso recebem esta permissão automaticamente na matriz.

Problemas comuns

Nova tela no código não aparece no menu
Cadastre a página aqui com controller_url igual ao slug da rota.
Controller_url errado
Deve ser kebab-case minúsculo, igual à URL (ex.: list-users).
