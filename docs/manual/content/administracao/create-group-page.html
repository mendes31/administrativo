Cadastrar Grupo de Página

Cria um novo grupo lógico para classificar páginas do sistema na estrutura de permissões.

Visão geral do módulo: consulte também o tópico Permissões — visão geral (adm-permissoes) para o fluxo completo da área.

Quem acessa: CreateGroupPage (e ListGroupsPages para acessar o formulário).

Fluxo principal (passo a passo)

  1. Em Grupos de Páginas, clique em Cadastrar.
  2. Informe um Nome claro (ex.: Financeiro, Segurança e Medicina).
  3. Opcionalmente preencha Observação para documentar o propósito do grupo.
  4. Salve e verifique o grupo na listagem.
  5. Ao cadastrar páginas, selecione este grupo no campo Grupo.

Campos e parâmetros

O que cada campo afeta no sistema.

Nome Obrigatório. Aparece na matriz de permissões agrupando as páginas.
Observação Texto interno para administradores; não afeta permissões.

Problemas comuns

Nome duplicado ou vazio
O sistema valida campos obrigatórios; use nome único e descritivo.
