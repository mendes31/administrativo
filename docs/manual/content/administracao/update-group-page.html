Grupos de Páginas — Editar

Altera nome e observação de um grupo existente. O ID permanece o mesmo; páginas vinculadas mantêm o vínculo.

Visão geral do módulo: consulte também o tópico Permissões — visão geral (adm-permissoes) para o fluxo completo da área.

Quem acessa: UpdateGroupPage.

Fluxo principal (passo a passo)

  1. Na listagem, clique em Editar no grupo desejado.
  2. Ajuste Nome e/ou Observação.
  3. Salve; a matriz de permissões passará a exibir o novo nome do grupo.

Campos e parâmetros

O que cada campo afeta no sistema.

Nome Atualiza o rótulo em toda a matriz ACL para páginas deste grupo.
Observação Apenas documentação administrativa.

Problemas comuns

Alteração não reflete para usuários
Nomes de grupo são cosméticos na matriz; permissões não mudam até alterar pacotes/níveis.
