Pacotes — Listar

Lista pacotes de páginas: conjuntos de permissões que serão atribuídos aos níveis de acesso (perfis).

Visão geral do módulo: consulte também o tópico Permissões — visão geral (adm-permissoes) para o fluxo completo da área.

Quem acessa: ListPackages; cadastro/edição com CreatePackage, UpdatePackage, DeletePackage.

Fluxo principal (passo a passo)

  1. Acesse Administração → Páginas → Pacotes.
  2. Filtre por nome se necessário.
  3. Crie pacotes por perfil funcional (ex.: CRM — Vendedor, Financeiro — Analista).
  4. Associe páginas a cada pacote ao cadastrar/editar em Listar Páginas.
  5. Marque os pacotes nos Níveis de Acesso (Cadastro).

Pacote vs. Grupo

Grupo organiza visualmente na matriz ACL. Pacote define quais páginas um perfil pode receber em bloco via nível de acesso.

Campos e parâmetros

O que cada campo afeta no sistema.

Nome (filtro) Busca na listagem sem alterar dados.
Nome do pacote Identificação usada ao vincular páginas e níveis de acesso.

Problemas comuns

Pacote vazio (sem páginas)
Atribuir pacote a um nível não libera menu até haver páginas vinculadas ao pacote.
