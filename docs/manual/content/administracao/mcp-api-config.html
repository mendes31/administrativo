Configuração API MCP

Função no sistema

Define o endpoint usado pelo chat Tiarajuzinho do Portal (navbar). Pode apontar para um servidor MCP externo ou para o piloto local de indicadores de RH.

Visão geral do módulo: consulte também o tópico Configurações do sistema (adm-configuracoes). Detalhes do piloto: docs/CHAT_INTERNO_TESTE_LOCAL.md.

Quem acessa: usuários com permissão McpApiConfig (configurar). Uso do chat exige McpChat.

Fluxo principal (passo a passo)

  1. Acesse Configuração API MCP em Administração.
  2. Para teste na homologação local (sem SAP e sem API paga), informe local:internal, ative a integração e salve.
  3. Com permissão McpChat, abra o chat no menu e pergunte, por exemplo: «quantos colaboradores ativos?», «quantos inativos?», «ativos na TI», «inativos» e depois «por mês», «quais relatórios no chat?» ou «relatório [nome]».
  4. Para gerir o catálogo de tools e liberar relatórios no chat, use Tools do Assistente MCP.
  5. Para servidor MCP externo, informe a URL HTTPS do agente e mantenha a opção ativa.

Campos e parâmetros

O que cada campo afeta no sistema.

URL da API MCP Endereço do servidor de agente, ou o valor especial local:internal para o piloto RH no MySQL do Portal.
Ativar integração Se desmarcado, o chat não aparece / não responde mesmo com URL preenchida.
LLM (API) Chaves (OPENAI_API_KEY, ANTHROPIC_API_KEY) ficam no .env do servidor — não na tela. URL local:internal e ativar/desativar podem ficar nesta janela. Ver docs/CHAT_INTERNO_TESTE_LOCAL.md.

Problemas comuns

Não vejo o menu desta tela
Permissão McpApiConfig ausente no seu nível de acesso.
Chat não aparece no navbar
Confira se a API está ativa, a URL preenchida e se o usuário tem McpChat.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação. Inclua a página filha no pacote.
«ativos na TI» misturava outros departamentos
Corrigido no piloto: nomes curtos usam igualdade (não LIKE). Sinônimos como «tecnologia da informação» mapeiam para TI.
Pediu gráfico/dashboard e não veio
No modo local:internal, o chat mostra gráfico quando a resposta traz série tipada (ex.: «headcount por departamento») ou um relatório dinâmico com visualização de gráfico e colunas rótulo+número. Dashboards completos continuam na área de Relatórios / Dashboards.
Como baixar o gráfico ou a planilha
Nas respostas com dados/gráfico, use a barra Baixar: PNG do gráfico, Excel/CSV dos dados do chat. Em relatórios dinâmicos, também há Excel/CSV/PDF completos (exige permissão de exportação do relatório).
Como ampliar o gráfico
Clique no gráfico da resposta para abrir em tamanho maior; feche com o X ou clicando fora.
Digitei só «financeiro» e a resposta não bateu com o que eu tinha pedido
O piloto guarda a última intenção (ativos/inativos) na sessão. Peça «ativos» ou «inativos» e em seguida o departamento. Frases completas («ativos no Financeiro») também funcionam.
