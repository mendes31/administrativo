Assistente MCP

Função no sistema

Centraliza os parâmetros do Assistente MCP (Tiarajuzinho): conexão com o servidor (URL / piloto local), o motor de IA (Groq, Gemini, OpenAI, Claude ou Ollama, com chaves nesta tela) e o catálogo de tools (RH built-in + relatórios dinâmicos liberados no chat). O chat é transversal a vários departamentos; a permissão de uso (McpChat) fica no grupo ACL Configurações, não no CRM.

Visão geral do módulo: consulte também o tópico Configurações do sistema (adm-configuracoes). Detalhes do piloto: docs/CHAT_INTERNO_TESTE_LOCAL.md.

Quem acessa: configuração com McpApiConfig (aba Conexão). Aba Tools exige ListMcpChatTools; salvar metadados de relatório exige SaveMcpChatTool. Uso do chat exige McpChat.

O que significam os termos

Tool
Capacidade tipada que o chat pode executar (ex.: rh.count_active, report.run). Não é SQL livre.
Disponível no chat
Flag do relatório dinâmico que o inclui no catálogo do Assistente MCP.
local:internal
Modo piloto no MySQL do Portal (indicadores RH / salas / relatórios), sem servidor MCP externo pago.
Motor de IA
Provedor que lê o texto livre e monta os filtros (departamento, idade, período…). O PHP só executa a consulta combinada. Não é preciso cadastrar cada frase. Chaves ficam nesta tela; o .env é fallback.

Fluxo principal

  1. Acesse Administração → Configurações → Assistente MCP.
  2. Na aba Conexão, informe local:internal (homologação) ou a URL HTTPS do servidor MCP, ative a integração e salve.
  3. No bloco Motor de IA, escolha Usar agora (Automático, Groq, Gemini, OpenAI, Claude ou Ollama), cole a chave no provedor correspondente e clique em Testar IA e depois em Salvar.
  4. Na aba Tools, consulte as tools internas de RH e libere relatórios dinâmicos (nome da tool, descrição e exemplos).
  5. Com permissão McpChat, abra o chat no navbar e pergunte, por exemplo: «quantos colaboradores ativos?», «usuários maiores de 30 anos», «ativos da TI com mais de 30 anos», «departamento do Rafael», «Wladimir está bloqueado?», «quantos anos de empresa o X possui?», «bloqueados sem desligamento», «desligados por departamento», «lista de contratações em junho», «salas», «relatório [nome]», «vendas por mês», «vendas 08/2026» ou «itens». Depois de um relatório, digite o mês (08/2026, jun/26) ou só o código SAP com dígito (ex.: 43000001) para filtrar.

Campos e parâmetros

O que cada campo afeta no sistema.

URL da API MCP Endereço do servidor de agente, ou o valor especial local:internal para o piloto RH no MySQL do Portal. Em modo externo, o Portal envia POST com corpo {"message":"…"} (chave em minúsculas) para a URL configurada. APIs ERP que usam {"Message":"…"} (M maiúsculo) ou path fixo (ex.: /api/sales) exigem adaptador/proxy — não bastam colar a URL na tela.
Permissões no chat Abrir o Assistente exige McpChat. Cada consulta tipada exige também as páginas do nível do usuário (ex.: RH → ListUsers/ViewUser; salas → CreateBooking/ListMeetingRooms; relatórios → partilha do relatório + flag «Disponível no chat»). A listagem de ajuda mostra só o que o nível permite.
Ativar integração Se desmarcado, o chat não aparece / não responde mesmo com URL preenchida.
Motor de IA / Usar agora Qual provedor interpreta as perguntas. Automático tenta Groq → Gemini → OpenAI → Claude → Ollama (o primeiro com chave/URL). Trocar o motor não exige editar o .env.
Texto livre (IA) A IA identifica e combina os filtros da pergunta e escolhe se a resposta é contagem («quantos no Financeiro») ou lista de nomes («nomes dos usuários do Compras»). O PHP só executa. O selo da bolha mostra ia: groq quando o modelo roteou, mais a tool. Sem IA, o piloto local ainda reconhece algumas formulações.
Chave Groq / Gemini / OpenAI / Claude Cole a API key. Campo em branco mantém a chave já gravada. Marque Apagar a chave para remover. Os logs de alteração gravam apenas máscara, não a chave.
Testar IA Envia um ping ao motor de Usar agora (o primeiro com chave, se estiver em Automático). A faixa cinza/verde/vermelha aparece acima dos botões Salvar / Testar IA — role até lá se a página recarregar no topo. Verde + trecho da resposta = funcionando. Vermelho = chave, modelo ou rede. Enquanto testa, o botão mostra «Testando…».
URL do Ollama Ex.: http://127.0.0.1:11434. Vazio usa OLLAMA_URL do .env.
Modelo Ollama Escolhido na aba Conexão (lista via /api/tags). Cada chamada usa um modelo; fallbacks tentam o próximo se o principal falhar. Sem valor na tela, usa OLLAMA_MODEL do .env.
Disponível no Assistente MCP Liga ou desliga o relatório no catálogo do chat (aba Tools).
Nome da tool Identificador estável (ex.: headcount_ti). Se vazio ao ativar, gera a partir do nome do relatório.
Descrição para a IA Texto curto para ajudar o roteamento (Ollama/API).
Exemplos de perguntas Uma frase por linha; o chat usa esses textos para reconhecer o pedido.
Filtro por mês no chat Aceita competência em várias formas: 08/2026, 8/2026, 08/26, jun/2026, junho/2026, junho de 2026, 2026-08, esse mês, mês passado. Exemplos: «vendas 08/2026», «faturamento jun/26». Depois do relatório aberto, basta «08/2026». Código SAP (item/parceiro) continua só com dígito, ex. 43000001.
Você quis dizer? Se a frase não casa com uma regra, o chat lista opções próximas (relatórios liberados no chat e consultas do nível do usuário). Digite o número (1, 2…) ou clique na opção. Erros de digitação («fatuamento») também entram. A IA (Ollama/API), se configurada, só é usada quando não há sugestão local.

Problemas comuns

Não vejo o menu desta tela
Permissão McpApiConfig ausente. A tela fica em Administração → Configurações (não no CRM).
Testar IA falhou conectando em 192.168.x:5153/api/sales
Essa URL é a API MCP/ERP antiga, não o Ollama. Em Automático ela é ignorada. Use Groq/Gemini com a chave da tela. Limpe OLLAMA_URL no .env se ainda apontar para /api/sales.
Chat respondeu com a lista de exemplos (tool: chat.help)
A IA ainda não roteou (teste Groq falhou) ou omitiu um filtro. Confirme Testar IA verde. A IA deve combinar no mesmo JSON todos os critérios (ex.: «garantia da qualidade maiores de 30» → departamento + idade). Se a bolha listar 118 nomes sem setor, o departamento não entrou no filtro.
Não consegui usar a IA… SSL / unable to get local issuer certificate
O PHP do WAMP não tem o arquivo de certificados CA. O cliente de IA passa a tratar isso como as demais APIs HTTPS do Portal. Recarregue a página, clique em Testar IA e tente o chat de novo.
Testar IA falhou (HTTP 401/403)
Chave inválida ou revogada. Gere outra no console do provedor (Groq, Google AI Studio, OpenAI ou Anthropic) e cole de novo. Deixe o campo em branco só para manter a chave já salva.
Testar IA falhou (HTTP 404 no modelo)
O catálogo do Groq/Gemini muda. Abra o console, copie o ID do modelo disponível e selecione (ou peça para cadastrar esse nome).
Chat não usa a chave nova
O teste pode passar com o valor do formulário, mas o chat lê o que está salvo. Clique em Salvar depois do teste.
«Sem permissão para esta consulta»
McpChat só abre o Assistente. Inclua no nível as páginas do módulo (ex.: RH → ListUsers/ViewUser). A ajuda do chat lista só o que o nível permite.
Pediu contratações e veio lista de desligados
Corrigido: «contratações»/«admissões» usam a data de admissão (`rh.list_hired`). Desligados continuam em «lista de desligados».
Tabela da listagem cortava nomes/departamento
Listagens nominativas (contratações, desligados) passam a cards empilhados na bolha; Excel/CSV mantém a grade completa. Relatórios largos usam rolagem horizontal dentro da área.
URL antiga list-mcp-chat-tools
Redireciona para mcp-api-config?tab=tools.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação. Inclua a página filha (ex.: SaveMcpChatTool) no pacote.
«ativos na TI» misturava outros departamentos
Corrigido no piloto: nomes curtos usam igualdade (não LIKE). Sinônimos como «tecnologia da informação» mapeiam para TI.
Pediu gráfico/dashboard e não veio
No modo local:internal, o chat mostra gráfico quando a resposta traz série tipada (ex.: «headcount por departamento») ou um relatório dinâmico com visualização de gráfico e colunas rótulo+número.
Salas de reunião no chat
Além de McpChat, libere no nível: ListMeetingRooms/BookRoom/RoomCalendar (listar/agenda), CreateBooking (reservar) e CancelBooking (cancelar).
Salvei o relatório mas o chat não encontra
Confirme modo local:internal ativo, flag «Disponível no chat» e se o utilizador do chat tem ACL para ver o relatório.
Digitou «faturamento» e veio a lista enorme de ajuda
Corrigido: o chat sugere «Você quis dizer?» com opções numeradas (só o que o nível permite). Digite 1 ou clique. «limpar» zera as sugestões.
Pediu «vendas por mês» e o chat procurou o código «mes»
Corrigido: «vendas por mês» abre o relatório completo. Para um mês: «vendas 08/2026» ou «vendas jun/26». Código SAP (item/parceiro) continua só com dígito, ex. 43000001.
Chat devolve HTTP 502 / Cloudflare ao abrir «Vendas por cliente»
O túnel não aguenta devolver dezenas de milhares de linhas. O chat passa a usar SELECT TOP 15. No SQL do relatório, agregue: GROUP BY cliente e SUM do líquido, com ORDER BY do total. «Vendas por mês» já é agregado, por isso costuma passar.
Tabela/gráfico do chat veio com data ISO e valor sem R$
A bolha formata pelo tipo do valor (mês 08/2026, moeda R$ 1.234,56). Excel/CSV do chat continuam com o número cru para somar na planilha. Atualize a página (Ctrl+F5) e pergunte de novo.
Listei vários Rafaéis e digitei TI — veio headcount
Corrigido: a lista fica na sessão; digite o departamento, o username ou o número (1, 2…). Na bolha da resposta aparece o selo tool: rh.lookup_person.
