Visualizar Filial / Estabelecimento

Função no sistema

Exibe Matriz ou Filial em modo somente leitura: tipo, CNPJ, razão social, nome fantasia, nome interno, código e contatos.

Visão geral do módulo: consulte a listagem de Filiais e o cadastro para o significado de cada campo.

Quem acessa: usuários com permissão ViewBranch.

Fluxo principal (passo a passo)

  1. Na listagem, clique em Visualizar.
  2. Confira tipo (Matriz/Filial), CNPJ, razão social, nome fantasia, endereço completo e telefone/e-mail.
  3. Use os botões do cabeçalho para listar, editar ou consultar o log de alterações.

Campos e parâmetros

O que cada campo afeta no sistema.

Dados exibidos Espelham o estado atual do registro; use Editar para modificar.

Problemas comuns

Não vejo o menu desta tela
Permissão ViewBranch ausente no seu nível de acesso.
