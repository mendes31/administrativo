Configurações do sistema

Função no sistema

Centraliza parâmetros de e-mail, notificações automáticas, calendário, integrações (SAP, MCP, Push PWA), WhatsApp, política de senha e cadastro de filiais (estabelecimentos).

Quem acessa: administradores com permissões EmailConfig, NotificationSettings, SapApiConfig, WhatsAppConfig, PasswordPolicy, ListBranches, etc.

Fluxo principal (passo a passo)

  1. Acesse Administração → Configurações e escolha a tela desejada.
  2. Em E-mail, informe servidor SMTP, porta, usuário, senha e remetente; salve e teste envio.
  3. Em Notificações Automáticas, ative gatilhos (treinamentos, folha, SST) e canais.
  4. Configure SAP API com endpoint, autenticação e timeout.
  5. Ajuste WhatsApp (token, número, webhook) se usar mensagens transacionais.
  6. Defina Política de Senha e cadastre Filiais (Matriz/Filial com CNPJ) para uso multi-módulo.

Configuração de E-mail

Servidor SMTP / Porta Host e porta (TLS recomendado).
Usuário / Senha SMTP Credenciais de autenticação do remetente.
Remetente padrão Nome e e-mail exibidos nas mensagens automáticas.

Notificações automáticas

Cada evento (treinamento vencendo, documento folha, pendência SST) pode disparar e-mail, push ou WhatsApp conforme habilitado.

SAP e integrações

URL base Endpoint da API SAP ou integração configurada.
Autenticação Token ou usuário/senha conforme ambiente.

WhatsApp

Token / Número Credenciais da API oficial ou provedor homologado.

Política de senha

Complexidade Tamanho mínimo, caracteres especiais, validade em dias.
Histórico Impede reutilização das últimas N senhas.

Filiais / estabelecimentos

Cadastro transversal de Matriz e Filiais (CNPJ) em Administração → Configurações → Filiais (permissão ListBranches). Usado por GP (empresa contratante), filtros e outros módulos.

Código / Nome fantasia Identificação usada em filtros, empresa contratante do usuário e relatórios multi-unidade.
Status Filiais inativas não aparecem no filtro global.

Campos e parâmetros

Mapa do módulo Links e resumos das telas cobertas por esta visão geral.
Permissões Cada tela operacional exige a página correspondente no nível de acesso.
Ajuda contextual (F1) Em cada tela de destino, o F1 abre o tópico detalhado daquela função.

Problemas comuns

E-mails caem em spam
Configure SPF/DKIM no domínio; use endereço corporativo válido.
SAP retorna 401/403
Credenciais expiradas ou usuário sem permissão na API.
WhatsApp não entrega
Verifique template aprovado, número verificado e limite da API.
Política de senha não aplica
Usuários podem precisar trocar senha no próximo login.
Filial não aparece no filtro
Cadastro inativo ou usuário sem vínculo à filial no perfil.
