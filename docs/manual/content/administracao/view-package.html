Visualizar Pacote

Função no sistema

Consulta dados do pacote e histórico de alterações (log disponível no cabeçalho).

Visão geral do módulo: consulte também o tópico Permissões — visão geral (adm-permissoes) para o fluxo completo da área.

Quem acessa: ViewPackage.

Fluxo principal (passo a passo)

  1. Abra Visualizar na listagem de pacotes.
  2. Use o botão de log para ver quem alterou o registro.

Campos e parâmetros

Cabeçalho Identificação do registro (código, nome, status).
Blocos de dados Seções com atributos, histórico ou vínculos relacionados.
Ações Editar e demais botões conforme permissão e estado do registro.
