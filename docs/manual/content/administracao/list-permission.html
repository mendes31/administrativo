Matriz de permissões — Listar

Exibe a matriz de permissões de um nível de acesso: todas as páginas agrupadas por grupo, com checkboxes para autorizar ou negar cada tela.

Visão geral do módulo: consulte também o tópico Permissões — visão geral (adm-permissoes) para o fluxo completo da área.

Quem acessa: ListPermission (acesso via Cadastro → Níveis de Acesso → Permissões).

Fluxo principal (passo a passo)

  1. Em Níveis de Acesso, abra o nível desejado e clique em Permissões.
  2. Use a busca Buscar por grupo para localizar áreas (Financeiro, SST…).
  3. Expanda/colapse grupos com os botões ou clique no cabeçalho do grupo.
  4. Marque ou desmarque checkboxes das páginas que o perfil deve acessar.
  5. Clique em Salvar para gravar a matriz (exceto nível Super Administrador, somente leitura).
  6. Exporte PDF para documentação de auditoria se necessário.
  7. Peça aos usuários logout/login para recarregar permissões da sessão.

Super Administrador

O nível Super Administrador tem matriz bloqueada (somente leitura) com acesso total implícito.

Erro 004

Usuário com página de listagem mas sem página de create/update/delete recebe erro 004 na ação. Inclua todas as páginas do fluxo no pacote.

Campos e parâmetros

O que cada campo afeta no sistema.

Buscar por grupo Filtra visualmente grupos na matriz; não altera dados até salvar.
Checkbox da página Autoriza (marcado) ou remove permissão explícita (desmarcado) para aquele nível.
Status / Tipo Indica se a página está ativa e se é pública ou padrão.
Expandir / Colapsar todos Facilita navegação em matrizes grandes.
Salvar Persiste todas as alterações da matriz para o nível de acesso atual.

Problemas comuns

Salvei mas usuário não vê menu
Confirme pacote no nível de acesso, página ativa e logout/login.
Checkbox não salva
Nível Super Admin é somente leitura; use outro nível de teste.
