Tools do Assistente MCP

Função no sistema

Este tópico foi unificado na tela Assistente MCP (mcp-api-config), aba Tools. A URL list-mcp-chat-tools redireciona para lá.

Consulte o tópico completo: Assistente MCP (mcp-api-config).

Quem acessa: ListMcpChatTools (ver aba). Salvar metadados exige SaveMcpChatTool.

Fluxo principal

  1. Abra Administração → Configurações → Assistente MCP.
  2. Selecione a aba Tools.
  3. Marque relatórios como disponíveis no chat, preencha tool / descrição / exemplos e salve.

Campos e parâmetros

Disponível no Assistente MCP Liga ou desliga o relatório no catálogo do chat.
Nome da tool Identificador estável (ex.: headcount_ti).
Descrição para a IA Texto curto para roteamento.
Exemplos de perguntas Uma frase por linha.

Problemas comuns

Não vejo a aba Tools
Permissão ListMcpChatTools ausente no nível de acesso.
Erro 004 ao salvar
Inclua a página SaveMcpChatTool no pacote de permissões.
