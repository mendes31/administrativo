Tools do Assistente MCP

Função no sistema

Centraliza o catálogo de tools do Assistente MCP no modo local:internal: tools internas de RH (somente leitura) e relatórios dinâmicos que podem ser liberados para o chat, com nome da tool, descrição e exemplos de perguntas.

Visão geral: configure a URL em Configuração API MCP (mcp-api-config). Para IA de roteamento/análise use chaves no .env (OPENAI_API_KEY ou ANTHROPIC_API_KEY, ou Ollama) — sem n8n. Detalhes: docs/CHAT_INTERNO_TESTE_LOCAL.md.

Quem acessa: usuários com permissão ListMcpChatTools. Salvar metadados exige SaveMcpChatTool. A edição do relatório também exige permissão de edição daquele relatório (criador ou acesso total). Exportar Excel/CSV/PDF completo pelo chat exige as páginas ExportDynamicReportExcel / ExportDynamicReportCsv / ExportDynamicReportPdf.

O que significam os termos

Tool
Capacidade tipada que o chat pode executar (ex.: rh.count_active, report.run). Não é SQL livre.
Disponível no chat
Flag do relatório dinâmico que o inclui no catálogo do Assistente MCP.

Fluxo principal

  1. Acesse Administração → Tools do Assistente MCP.
  2. Consulte as tools internas de RH (sempre disponíveis no piloto local).
  3. No acordeão de relatórios, marque Disponível no Assistente MCP, preencha tool / descrição / exemplos e salve.
  4. No chat, use «quais relatórios no chat?» ou um dos exemplos cadastrados.

Campos e parâmetros

Disponível no Assistente MCP Liga ou desliga o relatório no catálogo do chat.
Nome da tool Identificador estável (ex.: headcount_ti). Se vazio ao ativar, gera a partir do nome do relatório.
Descrição para a IA Texto curto para ajudar o roteamento (Ollama/API).
Exemplos de perguntas Uma frase por linha; o chat usa esses textos para reconhecer o pedido.

Problemas comuns

Não vejo o menu
Permissão ListMcpChatTools ausente. A migração replica ACL de McpApiConfig; confira o nível de acesso.
Salvei mas o chat não encontra o relatório
Confirme modo local:internal ativo, flag «Disponível no chat» e se o utilizador do chat tem ACL para ver o relatório (público / partilha / criador).
Gráfico no chat usa a coluna id
Corrigido: o chat só monta gráfico com colunas de métrica (total, quantidade, valor…). Listas só com id+nome mostram tabela, sem gráfico enganoso.
«inativos em janeiro» virou departamento
Corrigido: meses são período (desligamentos por data_desligamento), não nome de departamento.
Erro 004 ao salvar
Inclua a página SaveMcpChatTool no pacote de permissões.
