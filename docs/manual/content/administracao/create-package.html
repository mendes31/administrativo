Cadastrar Pacote

Registra um novo pacote para agrupar páginas que serão liberadas juntas a um nível de acesso.

Visão geral do módulo: consulte também o tópico Permissões — visão geral (adm-permissoes) para o fluxo completo da área.

Quem acessa: CreatePackage.

Fluxo principal (passo a passo)

  1. Em Pacotes, clique em Cadastrar.
  2. Defina Nome alinhado ao perfil (ex.: RH — Gestor).
  3. Documente em Observação quais áreas o pacote cobre.
  4. Salve e vincule páginas em Cadastrar/Editar Página (campo Pacote).

Campos e parâmetros

O que cada campo afeta no sistema.

Nome Exibido na seleção de pacotes ao editar páginas e níveis de acesso.
Observação Referência interna para equipe de TI.
