Permissões - Grupos, Pacotes e Páginas

Função no sistema

Estrutura ACL: grupos organizam pacotes; pacotes agrupam páginas (controllers); níveis de acesso recebem pacotes.

Telas desta área

Pressione F1 em cada tela para abrir a ajuda específica com fluxo e parâmetros.

  • Grupos de Páginas - list-groups-pages, create-group-page, update-group-page, view-group-page
  • Pacotes - list-packages, create-package, update-package, view-package
  • Páginas (ACL) - list-pages, create-page, update-page, view-page
  • Matriz de permissões - list-permission, update-permission (via Cadastro → Níveis de Acesso)

Quem acessa: administradores com ListGroupsPages, ListPackages, ListPages e ListAccessLevels.

Grupos fatiados: RH, SST e LGPD usam subgrupos na matriz (Gestão de Pessoas - …, SST - …, LGPD - …). Detalhe em Liberar Permissões (list-access-levels-permissions). O menu lateral do app não é montado por esses grupos.

Fluxo principal (passo a passo)

  1. Cadastre Grupos de Páginas por área (ou use os já existentes, inclusive os prefixados GP/SST/LGPD).
  2. Crie Pacotes vinculados a grupos; cada pacote representa um perfil funcional.
  3. Registre Páginas (slug do controller) e associe ao grupo adequado (ao criar página nova, analise se cabe num grupo existente ou exige grupo novo).
  4. Em Cadastro → Níveis de Acesso → Permissões, autorize páginas ou subgrupos necessários.
  5. Teste com usuário de homologação (logout/login) antes de produção.

Modelo ACL

Usuário → Nível de Acesso → Pacotes → Páginas (controllers)

Erro 004 indica falta de permissão na ação específica dentro da página.

Campos e telas

Grupo Agrupamento lógico de pacotes.
Pacote Conjunto de páginas liberadas (ex.: CRM - Vendedor).
Página Entrada ACL mapeada ao controller (ex.: CrmListOpportunities).
Nível de acesso Perfil atribuído ao usuário.

Problemas comuns

Menu SST incompleto após Autorizar Grupo
Com a cisão ACL, autorize os subgrupos SST - … necessários (EPI, Equipamentos, Medicina, etc.), não o legado “Segurança e Medicina” (pode estar vazio). Relogue o usuário. Detalhe em Liberar Permissões.
Menu aparece mas ação retorna erro 004
Usuário tem listagem, mas não criar/editar; inclua páginas filhas no pacote.
Nova tela não aparece no menu
Cadastre a página e inclua no pacote do nível de acesso.
Alteração não reflete imediatamente
Usuário precisa logout/login para recarregar permissões.
Pacotes sobrepostos confundem perfis
Documente qual perfil usa qual pacote; evite duplicidade desnecessária.
