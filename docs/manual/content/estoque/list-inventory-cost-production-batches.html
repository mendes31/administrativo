Lotes produzidos

Cadastro global de produção sincronizada do SAP (depósitos TJQP e APQP). Cada linha é um lote/entrada; use os filtros por data para conferir um intervalo — o mesmo usado nos períodos de custeio.

Visão geral: Custeio e produção (est-custeio).

Quem acessa: permissão ListInvCostProductionBatches.

Eficiência por lote

A coluna Eficiência compara a quantidade produzida com o lote padrão (mín.) cadastrado no item:

eficiência = qty do lote ÷ lote padrão (ex.: 1.480 ÷ 1.500 = 98,67%).

Se aparecer —, cadastre o lote padrão em Estoque → Item → Dados gerais ou vincule o código ERP do lote ao item.

Eficiência no período (simulação)

Com vários lotes no intervalo do período:

eficiência período = Σ qty ÷ (N lotes × lote padrão)

Esse valor ajusta o CVAR de matéria-prima na simulação (÷ eficiência). Embalagens não são ajustadas.

Fluxo principal

  1. Execute Sync completa SAP ou Sync incremental.
  2. Confira lote padrão nos itens produzidos.
  3. Filtre por datas do período analítico para validar eficiência lote a lote.
  4. Na Simulação de custos, selecione o período para aplicar a eficiência agregada.

Problemas comuns

Eficiência sempre —
Item sem lote padrão ou lote SAP sem vínculo inv_item_id/ERP no cadastro.
Eficiência > 100%
Produção acima do lote teórico (overfill). O sistema aceita; revise se o lote padrão está correto.
Sem lotes no período na simulação
Confira datas do período, depósitos filtrados e se a sync SAP rodou para o intervalo.
