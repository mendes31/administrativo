Classes HVAC — critério 8

Função no sistema

Parametrização dos multiplicadores usados no rateio CFIX do critério 8 (energia HVAC / fatia 29-H). O SAP informa o código da UDF ClasseHvac em cada item; os fatores numéricos ficam nesta tela.

Visão geral: Custeio e produção (est-custeio).

Quem acessa: permissão ListInvEnergyClassFactors (salvar: SaveInvEnergyClassFactors).

Códigos SAP × sistema

  • NA — Não aplicável (padrão SAP) · multiplicador 0 · SKU não entra no rateio HVAC
  • CM — cápsula mole · fator inicial 1,2
  • PROB — probiótico · fator inicial 1,2
  • OTHER — legado planilha (OUTRO); não vem do SAP · fator 1,0

Multiplicadores

Valores iniciais alinhados à planilha Tiaraju 202605 (linha 1232 — fator correção secagem) para CM/PROB. NA permanece em 0 para itens sem climatização aplicável ao rateio.

Fluxo

  1. Menu Estoque → Cadastros Bases → Classes HVAC (crit. 8).
  2. Revise descrição, multiplicador e observações de cada linha.
  3. Clique em Salvar multiplicadores.
  4. Recalcule períodos de custeio em rascunho após alterar fatores.

Problemas comuns

Item com NA ainda aparece no crit. 8
Multiplicador NA deve ser 0. Recalcule o snapshot do período.
SAP com NA mas sistema mostra OTHER
Rode sincronização SAP após a UDF ClasseHvac estar ativa; versões antigas mapeavam vazio para OTHER.
