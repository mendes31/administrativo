Listar Itens de Estoque

Lista e filtra registros de Listar Itens de Estoque no módulo Estoque. Use esta tela para localizar itens, acessar visualização/edição e iniciar novos cadastros.

Visão geral do módulo: consulte também o tópico Cadastros de estoque (est-cadastros) para o fluxo completo da área.

Quem acessa: usuários com permissão ListInventoryItems.

Fluxo principal (passo a passo)

  1. Acesse o menu Estoque e abra Listar Itens de Estoque.
  2. Use os filtros no topo para restringir por nome, status ou outros critérios.
  3. Ajuste Mostrar N registros se precisar ver mais linhas por página.
  4. Use Sincronizar SAP para atualizar itens (por hash) e, em seguida, apenas as estruturas pendentes. Opções avançadas permitem sincronizar só itens ou só estruturas (completo).
  5. Clique em Visualizar, Editar ou Cadastrar conforme sua permissão.
  6. Pressione F1 nesta tela para reabrir esta ajuda contextual.

Campos e parâmetros

O que cada campo afeta no sistema.

Filtros de busca Código, descrição, grupo de itens (somente grupos SAP importados), linha de produção, forma farmacêutica e status ativo.
Mostrar N registros Controla paginação (10, 20, 50 ou 100 por página).
Cód. ERP / Grupo SAP Filtros compartilhados por todos os botões de sincronização na barra superior.
Sincronizar SAP Botão principal (uso diário): atualiza itens por hash e, em seguida, apenas estruturas pendentes. Retomada automática após falha da API está sempre ativa.
Avançado Opções de manutenção: Completa (catálogo inteiro + purge de itens fora dos grupos SAP), Só itens (cadastro sem BOM/rota) e Estruturas (completo) (varredura total de lista de materiais e rota).
Só itens (Avançado) Sincroniza apenas o cadastro de itens — útil com Completa marcada para carga inicial sem consultar estruturas. Com Grupo SAP (ex.: 100) + Completa, varre todos os itens daquele grupo; sem Completa, só itens alterados recentemente (inclui UpdateDate vazio no SAP).
Colunas Forma farm. e Linha Exibem os dados importados do SAP nos produtos acabados/intermediários. Itens sem valor no SAP aparecem como —.
Estruturas (completo) (Avançado) Reconsulta BOM e rota de todos os itens elegíveis (não só pendentes). Mais lento; use após migração ou quando estruturas parecerem desatualizadas.
Ações (Visualizar / Editar / Apagar) Dependem das permissões do seu nível de acesso além da listagem.

Problemas comuns

Não vejo o menu desta tela
Permissão ListInventoryItems ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
F1 abre documentação genérica
Este tópico ainda está em expansão; consulte a visão geral do módulo para o fluxo completo.
Sincronização demora ou expira
Itens e estruturas são ações separadas. Acompanhe o progresso na janela modal; ao concluir, clique em Atualizar listagem. Use sync incremental no dia a dia; reserve Completa para a carga inicial.
Incremental não trouxe item novo
Execute uma sincronização Completa uma vez, ou confira se o item foi alterado no SAP (UpdateDate) após a última sync registrada.
Sincronizar só um item ou um grupo
Na listagem, preencha Cód. ERP ou escolha Grupo SAP ao lado de Sincronizar SAP (ou use Avançado → Sincronizar itens). Para catálogo PA com forma e linha, use grupo 400.
Erro HTTP 500 da API SAP
Instabilidade momentânea ou consulta pesada. O sistema tenta reconectar automaticamente (até 10 vezes) e reduz o tamanho do lote. Aguarde ou tente de novo em alguns minutos.
Barra mostra mais verificados que o total ou fica em 99%
Em retomadas automáticas após instabilidade da API, o sistema inicia uma nova passagem pelo catálogo. O contador exibe Passagem N — X / total; os totais de Novos/Alterados/Sem mudança são acumulados. O percentual só chega a 100% quando a execução termina.
Barra de progresso não avança
Aguarde — a primeira consulta ao SAP pode levar 1–2 minutos. Estruturas mostram Consultando SAP — estrutura X/N item a item.
Segunda sync de estruturas não altera nada
Comportamento esperado: o sistema consulta o SAP, compara com o local e só grava quando há diferença. Se tudo já estiver igual, verá Sem alteração nos contadores e a mensagem Nenhuma estrutura alterada; a janela fecha automaticamente.
Segunda sync de itens ainda mostra centenas de Alterados
Se o SAP não mudou, o esperado é Sem mudança na maior parte. Muitos Alterados repetidos costumavam ocorrer quando o SAP envia MinOrdrQty = 0 (lote padrão) — o sistema grava o mínimo técnico 0,000001 no banco e a comparação antiga recontava o item a cada execução. Após a correção, rode a sync uma vez; na seguinte, só devem aparecer alterações reais (ex.: preencher Data SAP em itens que ainda não tinham esse campo).
Como interromper a sincronização
Na janela de progresso, clique em Interromper. Os itens já gravados permanecem no sistema; a operação para no próximo lote.
Sync falhou com HTTP 500
A API SAP pode ficar instável. Clique em Sincronizar SAP novamente — o sistema retoma automaticamente.
Lote padrão ou Administrar por diferente do SAP
A sincronização compara pelo código ERP e atualiza lote padrão (MinOrdrQty), administrar por (lote/série), estoque mín./máx. e demais campos. Se o hash SAP já estava gravado mas o cadastro local ficou desatualizado, rode Sincronizar SAP novamente (ou sync por código na barra). Itens com API instável podem ser importados via fallback parcial de colunas.
Campos vazios no SAP (UpdateDate ou UDF nulos) são importados como vazio e a sync continua. Se antes apareciam no log de falhas, rode a sincronização novamente após a correção da query.
Itens com falha na sincronização
Se a API não retornar o cadastro completo de um código ERP, o item é ignorado e a sync continua. O modal exibe a lista Itens com falha (código e motivo) em área com rolagem, para não aumentar demais o popup. A lista completa fica em logs/sap_sync_failures_{run_id}.log e no campo error_log da tabela inv_inventory_sap_sync_runs (JSON após o prefixo failures:).
Incremental removeu itens mas não importou novos
A remoção de itens fora do catálogo só ocorre na sync Completa. Use incremental no dia a dia apenas para itens alterados recentemente no SAP.
BOM/rota não importou; pendências continuam
O item pode estar inativo no SAP (validFor=N) ou sem versão BEAS — após a correção recente, rode Sincronizar SAP de novo ou o botão Estrutura na visualização. Se o SAP não tiver BOM/rota cadastrada, as pendências são encerradas com mensagem explicativa.
Forma farmacêutica ou linha vazia na listagem
Confirme se o SAP tem U_FormaFarma e U_LinhaProduto preenchidos para o item. Se estiverem vazios no SAP, a coluna permanece —. Ao preencher no SAP e sincronizar de novo, o sistema atualiza.
Itens inativos não aparecem
Confira o filtro Status na listagem (deixe em branco para ver ativos e inativos). Inativos no SAP (validFor = N) são importados com switch desmarcado após sync completa.
Itens de outros grupos SAP sumiram após sync
Comportamento esperado na sync Completa: só permanecem itens dos grupos 100, 200, 300, 400, 600, 700 e 1000. Cadastros manuais sem código ERP e itens PA - PROJETO não são removidos.
Sync informou itens não excluídos por vínculo
O item ainda aparece em movimentação de estoque ou como componente na BOM de outro PA. Resolva o vínculo ou inative o item manualmente.
Estrutura não apareceu após sincronizar
Confira se o item tem Código ERP, categoria PA/PI ou código 43…/40…, e se existe BOM/rota no BEAS para esse código.
