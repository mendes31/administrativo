Listar Itens de Estoque

Lista e filtra registros de Listar Itens de Estoque no módulo Estoque. Use esta tela para localizar itens, acessar visualização/edição e iniciar novos cadastros.

Visão geral do módulo: consulte também o tópico Cadastros de estoque (est-cadastros) para o fluxo completo da área.

Quem acessa: usuários com permissão ListInventoryItems.

Fluxo principal (passo a passo)

  1. Acesse o menu Estoque e abra Listar Itens de Estoque.
  2. Use os filtros no topo para restringir por nome, status ou outros critérios.
  3. Ajuste Mostrar N registros se precisar ver mais linhas por página.
  4. Use Sincronizar itens para importar/atualizar cadastro e custos de comprados do SAP (modo incremental por padrão; marque Completa na primeira carga).
  5. Use Sincronizar estruturas para atualizar BOM e rota (BEAS) em lote nos PA/PI e códigos 43…/40… elegíveis, sem abrir item a item.
  6. Clique em Visualizar, Editar ou Cadastrar conforme sua permissão.
  7. Pressione F1 nesta tela para reabrir esta ajuda contextual.

Campos e parâmetros

O que cada campo afeta no sistema.

Filtros de busca Restringem os registros exibidos na grade; não alteram dados, apenas a consulta.
Mostrar N registros Controla paginação (10, 20, 50 ou 100 por página).
Sincronizar itens Consulta o SAP e grava apenas novos itens ou alterações (descrição, categoria, custo MP/EMB, status). Incremental usa UpdateDate do SAP desde a última sync bem-sucedida. Marque Completa para importar todo o catálogo.
Sincronizar estruturas Atualiza lista de materiais e rota no BEAS para todos os itens elegíveis (PA/PI, códigos 43…/40… ou que já tenham BOM/rota local). Itens PA - PROJETO são ignorados. Sem estrutura no SAP, o cadastro local é mantido.
Ações (Visualizar / Editar / Apagar) Dependem das permissões do seu nível de acesso além da listagem.

Problemas comuns

Não vejo o menu desta tela
Permissão ListInventoryItems ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
F1 abre documentação genérica
Este tópico ainda está em expansão; consulte a visão geral do módulo para o fluxo completo.
Sincronização demora ou expira
Itens e estruturas são ações separadas. Use sync incremental no dia a dia; reserve Completa para a carga inicial. Estruturas em lote podem levar vários minutos — não feche a aba.
Incremental não trouxe item novo
Execute uma sincronização Completa uma vez, ou confira se o item foi alterado no SAP (UpdateDate) após a última sync registrada.
Estrutura não apareceu após sincronizar
Confira se o item tem Código ERP, categoria PA/PI ou código 43…/40…, e se existe BOM/rota no BEAS para esse código.
