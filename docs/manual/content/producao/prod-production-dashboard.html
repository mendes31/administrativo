Dashboard de Produção

Função no sistema

Painel gerencial da produção fabril com unidades produzidas (SKUs), produtos distintos, ordens e aderência ao plano. A fonte operacional é o BEAS (manufatura no SAP Business One) mais as entradas de estoque OIGN. O painel lê um cache MySQL sincronizado pela API SAP já parametrizada — não consulta o HANA a cada filtro. É independente do custeio fabril (Estoque/Custos).

O que significam os termos

SKU produzido
Unidades recebidas em estoque no período (soma de IGN1.Quantity das entradas OIGN ligadas ao BEAS). Não é contagem de códigos.
Produto produzido
Quantidade de ItemCode distintos recebidos no período (acabados com código 4%).
Volume produzido
A mesma soma de unidades do card SKUs; alimenta o gráfico realizado × planejado.
Ordem iniciada
Ordem cujo primeiro apontamento no BEAS (MIN(BEAS_ARBZEIT.ANFZEIT)) cai no período filtrado.
Ordem concluída
Posição principal encerrada no BEAS (ABGKZ = J) com data de encerramento no período.
Aderência ao plano
Quantidade recebida no período dividida pela quantidade planejada (BEAS_FTPOS.MENGE) das posições com data da ordem no período.
Depósito / linha
Filtro TJQP (químicos/softgel) ou APQP. “Ambos” equivale ao parâmetro AMBOS das queries do PCP. Só entram posições principais (STUFE = 0).
OEE
Eficiência global do equipamento (disponibilidade × performance × qualidade). Indicador da V1.1: a tela mostra “—” até existir apontamento de parada/ciclo no cache.
Cache MySQL
Entradas em adms_prod_receipt_fact, ordens em adms_prod_wo_fact, refugo diário em adms_prod_scrap_day. O painel lê só este cache.
Atualizar agora (incremental)
Botão que dispara sync incremental (HANA → MySQL, overlap de 7 dias). A carga completa (24 meses + OPs abertas) é só via CLI --full.

Quem acessa: usuários com permissão ProdProductionDashboard (dados via ProdProductionDashboardData; sync via ProdProductionDashboardSync). Super administrador vê o menu automaticamente; demais níveis recebem a permissão no cadastro de acesso. Grupo ACL: Produção.

Fluxo principal

  1. Execute a migration: vendor/bin/phinx migrate.
  2. Na primeira vez, rode a carga completa: php scripts/sync_prod_production_sap.php --full.
  3. Acesse Produção → Dashboard de Produção no menu lateral.
  4. Escolha o período (7/30/90 dias, mês atual/anterior, ano atual ou personalizado).
  5. Opcionalmente filtre por depósito (TJQP, APQP ou ambos).
  6. No personalizado, preencha as datas e clique em Atualizar.
  7. Para forçar atualização no meio do dia, use Atualizar agora (incremental). O 1º acesso do dia já sincroniza sozinho.
  8. Confira no rodapé a fonte do sync (BEAS) e as tabelas detectadas no probe.

Campos e parâmetros

Período Presets: últimos 7/30/90 dias, mês atual, mês anterior, ano atual (YTD) ou personalizado. Padrão: últimos 30 dias. Comparações “vs. período anterior” usam o mesmo número de dias imediatamente antes.
Data início / Data fim Visíveis só no período personalizado; aplicadas ao clicar em Atualizar.
Depósito TJQP, APQP ou ambos. Só acabados 4% e posição principal (STUFE = 0).
KPIs SKUs (unidades), produtos (códigos distintos), volume, ordens iniciadas/concluídas, em andamento, em atraso e aderência ao plano.
Gráficos SKUs e produtos por mês; realizado × planejado; iniciadas vs. concluídas; aderência por linha.
Tabelas Ordens em aberto (snapshot) e ranking de SKUs por volume.
API dados Endpoint prod-production-dashboard-data agrega só no MySQL.
API sync Endpoint prod-production-dashboard-sync — somente incremental na web. Full sync apenas via CLI.
CLI / cron php scripts/sync_prod_production_sap.php (incremental), --full (24 meses). Cron opcional se não quiser depender do 1º acesso do dia.

Problemas comuns

Não vejo o menu
O item fica em Produção → Dashboard de Produção (app/adms/Views/partials/menu.php). Recarregue a página (o cache de permissão de menu é invalidado pela migration). Confirme permissão ProdProductionDashboard no nível de acesso — Super administrador já vê todas as páginas ativas.
Cache vazio / aviso de sincronização
Rode php scripts/sync_prod_production_sap.php --full uma vez. Depois o 1º acesso do dia e o botão incremental mantêm o cache.
Números zerados com sync “OK”
Confirme se a API SAP alcança OIGN/IGN1 e U_beas_belnrid. Sem entradas de produção no recorte (item 4%, TJQP/APQP) o cache de produzido fica vazio mesmo com OPs no BEAS.
OEE, paradas e ciclo mostram “—”
Esperado na V1. Esses indicadores entram na V1.1. A taxa de refugo usa apontamento BEAS_ARBZEIT quando houver cache diário.
SKU e volume com o mesmo valor
Esperado: no glossário do PCP, SKUs produzidos são unidades; o card de volume repete essa soma para o gráfico realizado × planejado. Produtos são os códigos distintos.
Erro da API SAP / timeout no sync
Confirme a Configuração SAP API. O painel continua lendo o cache anterior.
Confundi com Recursos de Produção do Estoque
Cadastros de recurso/MO no Estoque servem ao custeio fabril. Este dashboard trata ordens reais do BEAS/SAP.
