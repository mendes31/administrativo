Visão geral — Dashboard

Função no sistema

Painel inicial do sistema com indicadores consolidados, atalhos e widgets conforme permissões do usuário. É a primeira tela após o login para quem possui acesso.

Quem acessa: todos os usuários com permissão Dashboard; gestores veem KPIs ampliados conforme pacote de páginas. Cards opcionais: DashboardCardInformativos, DashboardCardPolicies, DashboardCardTimeline, DashboardCardEventos, DashboardCardAniversariantes, DashboardCardTempoEmpresa, DashboardCardPayrollDocuments, DashboardCardEmployeePortal, DashboardCardMyCalendar, DashboardCardRoomBooking, DashboardCardGamificationQuizzes, DashboardCardPortaria.

Fluxo principal (passo a passo)

  1. Faça login e aguarde o carregamento do dashboard principal.
  2. Revise os cartões de indicadores (pendências, treinamentos, financeiro, SST) disponíveis no seu perfil.
  3. Use os atalhos ou links nos widgets para ir direto ao módulo relacionado.
  4. Aplique filtros globais (filial, período) quando disponíveis no topo da página.
  5. Pressione F1 em widgets com ajuda contextual para abrir o tópico correspondente.

Campos e telas

Widgets Blocos com gráficos, contadores e listas resumidas.
Filtro global Restringe dados por filial ou unidade organizacional.
Atalhos rápidos Links para cadastros, pendências e relatórios frequentes.
Indicadores por módulo SST, RH, financeiro e CRM aparecem conforme permissões.

Problemas comuns

Dashboard vazio ou sem widgets
Verifique se seu nível de acesso inclui a página Dashboard e se há dados no período filtrado.
Indicador diverge do relatório detalhado
Confirme filtros de filial e período; widgets podem usar janela de tempo diferente.
Não consigo acessar o dashboard
Permissão Dashboard ausente no nível de acesso. Solicite ao administrador.
F1 abre documentação em desenvolvimento
Alguns widgets ainda não têm tópico dedicado; consulte a visão geral do módulo relacionado.
