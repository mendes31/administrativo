Editar Candidato

Atualiza dados do candidato e permite anexar novo currículo ao histórico.

Quem acessa: permissão RhCandidatosEdit e autorização por objeto. A edição exige senha e justificativa.

Fluxo principal

  1. Altere os campos necessários.
  2. O status do processo é uma projeção dos vínculos com vagas — não é editado livremente. Use o pipeline para mudar etapas; opcionalmente marque contratado.
  3. (Opcional) Envie um novo arquivo de currículo — será adicionado como anexo adicional.
  4. Confirme com senha e justificativa.
  5. Salve.

Problemas comuns

Arquivo não sobe na edição
O formulário precisa enviar como multipart. Use PDF/DOC/DOCX até 10 MB.
Não consigo mudar o status no cadastro
Esperado: movimente no Kanban/pipeline da vaga. Status geral é recalculado automaticamente.
