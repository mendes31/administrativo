Criar Feedback de Desempenho

Registra um feedback contínuo para um colaborador (fora do PDI). O autor é sempre o usuário logado.

Quem acessa: CreatePerformanceFeedback.

Fluxo

  1. Desempenho → Feedbacks → Novo.
  2. Selecione o destinatário (gestor: só subordinados).
  3. Tipo, texto e opções anônimo/público.
  4. Salve e confira na visualização.

Público: gestor imediato do destinatário também vê. Anônimo: nome oculto para o destinatário.
