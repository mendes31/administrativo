Log de download de currículos

Função no sistema

Tela de auditoria LGPD que lista quem baixou anexos/currículos de candidatos. Os registros são gerados automaticamente no download autorizado; esta tela só consulta e exporta.

Quem acessa: ListRhCandidatoAnexoAccessLogs. Exportar Excel exige ExportRhCandidatoAnexoAccessLogsExcel. Por padrão a migration concede a quem já tem ListLogAcessos (auditoria).

O que significam os termos

LGPD
Lei Geral de Proteção de Dados — exige rastreabilidade de acesso a dados pessoais sensíveis, como currículos.
authorized_controller
Download via controller oficial de anexo do candidato.
legacy_file_server
Download via endpoint legado de arquivos (serve-file), com deduplicação de 60s.
Path hash
Hash SHA-256 do caminho do arquivo (sem expor o nome original na listagem).

Fluxo principal

  1. Menu Administração → Logs → Log download currículos (ou F1 nesta tela).
  2. Filtre por quem baixou, candidato, fonte, IP e período.
  3. Consulte a tabela; clique no candidato para abrir o cadastro (se ainda existir).
  4. Exporte Excel com os mesmos filtros quando precisar evidência para DPO.

Campos e parâmetros

Quem baixou Nome do usuário ator (parcial).
Candidato / ID Nome parcial ou ID numérico do candidato.
Fonte authorized_controller ou legacy_file_server.
IP / período Recorte técnico e temporal.
Excel Inclui user-agent e path hash além das colunas da tela.

Problemas comuns

Não vejo o menu
Permissão ausente — rode a migration de páginas e inclua no nível (espelha quem tem ListLogAcessos) ou conceda manualmente.
Lista vazia com downloads conhecidos
Confirme se a tabela rh_candidato_anexo_access_logs existe (migration 20260719231000) e se o período/filtros não estão estreitos demais.
Candidato aparece só com ID
O candidato pode ter sido anonimizado/excluído; o log permanece sem CASCADE.
