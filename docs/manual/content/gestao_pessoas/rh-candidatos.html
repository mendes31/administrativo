Listar Currículos / Candidatos

Função no sistema

Consulta e gestão dos currículos recebidos no recrutamento (ATS).

Visão geral: veja também Recrutamento e currículos (gp-recrutamento).

Quem acessa: usuários com permissão RhCandidatos para a listagem. Com RhCandidatosViewAll (ou Super) a listagem e a ficha mostram qualquer candidato; sem ViewAll, apenas vinculados a vagas em que o usuário é responsável — gestores CRM ainda acessam fichas. Candidatos sem vaga não aparecem no modo restrito. Download de anexos exige também RhCandidatosDownloadAnexo e a mesma autorização por objeto.

O que significam os termos

LGPD
Lei Geral de Proteção de Dados: regras para tratar dados pessoais com base legal, segurança e direitos do titular.

Fluxo principal

  1. Acesse Currículos / Candidatos no menu de Gestão de Pessoas.
  2. Use filtros (nome, status, origem) para localizar o candidato.
  3. Abra Visualizar para ver dados, vagas vinculadas e currículos anexados.
  4. Para incluir novo candidato, use Cadastrar — o consentimento LGPD é obrigatório.

Segurança e LGPD

  • Currículos novos ficam em armazenamento privado (não acessíveis por URL pública).
  • Download só para quem tem permissão de RH/recrutamento ou é responsável/gestor da vaga.
  • Cada download autorizado é registrado para auditoria LGPD (sem tela de consulta nesta versão).
  • Após o prazo de retenção, o sistema anonimiza dados e remove os arquivos físicos.

Campos e parâmetros

Filtros ou formulário Controles principais para consultar ou alterar dados nesta tela.
Resultado / painel Área onde o sistema mostra listagens, totais ou detalhe do registro.
Ações Botões e links disponíveis conforme sua permissão.

Problemas comuns

Não vejo o menu
Falta a permissão RhCandidatos no nível de acesso.
Só vejo candidatos das minhas vagas
Falta RhCandidatosViewAll. Após a migration de escopo, quem já tinha RhCandidatos recebe ViewAll automaticamente. Candidatos sem vínculo com vaga só aparecem com ViewAll.
Não consigo baixar o currículo
Confirme a permissão RhCandidatosDownloadAnexo e se está logado. Links antigos serve-file também exigem autorização.
Cadastro bloqueado por LGPD
É preciso marcar o consentimento e existir termo ativo do tipo curriculo_candidato.
