Calibrações de Desempenho

Sessões de calibração por ciclo: atas/notas, status e atalho para avaliações e Nine Box do ciclo.

Quem acessa: ListPerformanceCalibrations.

Fluxo principal

  1. Cadastre um ciclo (Desempenho → Ciclos) e vincule avaliações a ele.
  2. Abra Desempenho → Calibração → Nova Calibração escolhendo o ciclo.
  3. Registre notas da sessão; use o link Nine Box do ciclo.
  4. Ao finalizar, altere o status para Travada (não reabre neste incremento).

Problemas comuns

Não há ciclos no formulário
Crie um ciclo em rascunho/aberto que ainda não tenha calibração.
Nine Box vazio com ciclo
Só entram avaliações concluídas vinculadas àquele ciclo.
