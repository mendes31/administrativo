Criar Tipo de Solicitação

Função no sistema

Cadastra um novo tipo (código, nome, campos). Depois de criar, abra Editar para montar o fluxo (1ª etapa / 2ª etapa / exceções).

Quem acessa: CreateRequestType.

Passo a passo

  1. Em Tipos de Solicitação, clique em Cadastrar.
  2. Informe código único (ex.: vacation), nome e se precisa datas/dias/valor.
  3. Salve.
  4. Na listagem, clique em Editar no tipo criado e monte o fluxo etapa a etapa — veja o tópico Editar Tipo de Solicitação.

Problemas comuns

Criei o tipo mas o fluxo não aparece
O fluxo completo fica na tela Editar, não na criação. Edite o registro após salvar.
