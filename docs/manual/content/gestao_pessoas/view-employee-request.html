Visualizar Solicitação

Função no sistema

Exibe os dados de um registro de Visualizar Solicitação em modo somente leitura, com atalhos para editar ou excluir quando permitido.

Visão geral do módulo: consulte também o tópico Solicitações (gp-solicitacoes) para o fluxo completo da área.

Quem acessa: usuários com permissão ViewEmployeeRequest.

Fluxo principal (passo a passo)

  1. Na listagem, clique em Visualizar no registro desejado.
  2. Revise ID, datas de cadastro/edição e observações.
  3. Se você for aprovador, use os botões de aprovar/rejeitar quando a solicitação estiver na sua etapa.
  4. Consulte a linha do tempo do workflow no final da página (criação, aprovações, escalações e etapa atual).
  5. Ao abrir a tela, notificações pendentes desta solicitação são marcadas como lidas no sino.
  6. Use os botões do cabeçalho para ir à listagem, editar ou consultar log de alterações.

Campos e parâmetros

O que cada campo afeta no sistema.

Dados exibidos Espelham o estado atual do registro no banco; use Editar para modificar.

Problemas comuns

Não vejo o menu desta tela
Permissão ViewEmployeeRequest ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
Pressione F1 nesta tela para reabrir esta ajuda contextual
