Requisições de Pessoal

Função no sistema

Solicita e aprova necessidade de contratação (headcount) antes de abrir a vaga no ATS.

Visão geral: Recrutamento (gp-recrutamento).

Quem acessa: permissões RhPersonnelRequests, RhPersonnelRequestsCreate, RhPersonnelRequestsView, RhPersonnelRequestsApprove, RhPersonnelRequestsReject e RhPersonnelRequestsConvert (mesmos níveis que já acessam Vagas, após a migration).

O que significam os termos

JR / PL / SR
Níveis de senioridade no cadastro do cargo (Júnior, Pleno, Sênior). Na requisição o sistema mostra o nome completo do cargo, para distinguir registros que só diferem pela senioridade.
Área
Departamento solicitante (cadastro de departamentos).

Fluxo principal

  1. Crie a requisição escolhendo Área e Cargo, quantidade e justificativa.
  2. Ao escolher a área, a lista de cargos é filtrada pelos cargos já usados por colaboradores Ativos daquela área. Marque Mostrar todos os cargos se a função for nova na área.
  3. Outro usuário com permissão aprova ou rejeita (não pode ser o solicitante).
  4. Se aprovada, use Converter em vaga — a vaga nasce pausada para completar detalhes e abrir o pipeline.

Campos e parâmetros

Área Departamento da necessidade; filtra a lista de cargos (salvo “Mostrar todos”).
Cargo Nome completo como cadastrado em Cargos (inclui JR/PL/SR). O valor gravado é o id do cargo.
Mostrar todos os cargos Desliga o filtro por área e lista todo o cadastro de cargos.
Quantidade / Contrato / Motivo / Data desejada / Faixa salarial / Justificativa Detalhes da necessidade enviados à aprovação.
Ações Aprovar, rejeitar e converter em vaga conforme status e permissão.

Problemas comuns

Cargos “iguais” na lista
São registros distintos (ex.: Analista JR, PL e SR). Nesta tela o nome completo aparece para diferenciá-los.
Cargo não aparece após escolher a área
O filtro usa lotação atual de colaboradores ativos. Marque Mostrar todos os cargos para funções novas na área.
Não é permitido aprovar a própria requisição
Peça a outro aprovador RH/gestor com a permissão.
Erro ao carregar requisições
Rode a migration 20260719160000_create_rh_personnel_requests.
Já foi convertida
Cada requisição gera no máximo uma vaga; abra a vaga vinculada.
