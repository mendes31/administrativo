List Policies

Lista e filtra registros de List Policies no módulo Gestão de Pessoas. Use esta tela para localizar itens, acessar visualização/edição e iniciar novos cadastros.

Visão geral do módulo: consulte também o tópico Políticas internas (gp-politicas) para o fluxo completo da área.

Quem acessa: usuários com permissão ListPolicies.

Fluxo principal (passo a passo)

  1. Acesse o menu Gestão de Pessoas e abra List Policies.
  2. Use os filtros no topo para restringir por nome, status ou outros critérios.
  3. Ajuste Mostrar N registros se precisar ver mais linhas por página.
  4. Clique em Visualizar, Editar ou Cadastrar conforme sua permissão.
  5. Pressione F1 nesta tela para reabrir esta ajuda contextual.

Campos e parâmetros

O que cada campo afeta no sistema.

Filtros de busca Restringem os registros exibidos na grade; não alteram dados, apenas a consulta.
Mostrar N registros Controla paginação (10, 20, 50 ou 100 por página).
Ações (Visualizar / Editar / Apagar) Dependem das permissões do seu nível de acesso além da listagem.

Problemas comuns

Não vejo o menu desta tela
Permissão ListPolicies ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
F1 abre documentação genérica
