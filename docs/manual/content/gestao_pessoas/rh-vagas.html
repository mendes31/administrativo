Listar Vagas

Consulta e gerencia vagas do recrutamento (ATS), com filtros por status, área e cargo.

Visão geral do módulo: consulte também o tópico Recrutamento (gp-recrutamento).

Quem acessa: permissão RhVagas. Com RhVagasViewAll (ou Super Admin) a listagem mostra todas as vagas; sem essa permissão, apenas as vagas em que o usuário é responsável.

Fluxo principal

  1. Acesse Vagas de Emprego no menu Recrutamento.
  2. Use filtros (título, status, área, cargo) e abra o detalhe ou o pipeline.
  3. Para abrir uma vaga a partir de headcount aprovado, use Requisições.

Problemas comuns

Só vejo minhas vagas
Falta a permissão RhVagasViewAll no nível de acesso. Após a migration de escopo, quem já tinha RhVagas recebe ViewAll automaticamente; se foi removida depois, solicite a inclusão.
Não vejo o menu desta tela
Permissão RhVagas ausente no seu nível de acesso.
Erro ao carregar após deploy
Rode a migration 20260719210000_register_rh_vagas_view_all_scope.
