Cadastrar Candidato

Função no sistema

Inclui um candidato/currículo no banco de recrutamento, com registro de consentimento LGPD.

Quem acessa: permissão RhCandidatosCreate.

O que significam os termos

LGPD
Lei Geral de Proteção de Dados: regras para tratar dados pessoais com base legal, segurança e direitos do titular.

Fluxo principal

  1. Preencha nome e demais dados do candidato.
  2. (Opcional) Anexe o currículo em PDF, DOC ou DOCX (máx. 10 MB).
  3. Leia o termo LGPD exibido e marque o checkbox de consentimento do titular.
  4. Salve. O sistema grava o consentimento em lgpd_consentimentos e vincula ao candidato.

Campos importantes

Currículo Arquivo opcional; armazenado em área privada.
Consentimento LGPD Obrigatório. Declara que o titular consentiu o tratamento para recrutamento.
Status do processo Inicia como Candidatado; depois é projeção automática dos vínculos/pipeline.

Problemas comuns

Mensagem pedindo termo LGPD
Cadastre/ative um termo do tipo curriculo_candidato no módulo LGPD (a migration de segurança já cria um termo padrão).
Arquivo rejeitado
Use PDF/DOC/DOCX até 10 MB; o conteúdo precisa corresponder à extensão.
