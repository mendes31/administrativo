Listar Tipos de Solicitação

Função no sistema

Catálogo dos tipos que o colaborador pode abrir no Portal (férias, documento, etc.). O fluxo de aprovação de cada tipo se configura na tela Editar — não nesta listagem.

Ajuda detalhada do fluxo: abra um tipo → Editar → pressione F1 (tópico Editar Tipo de Solicitação).

Quem acessa: ListRequestTypes.

Como chegar no fluxo (passo a passo)

  1. Menu Gestão de Pessoas → Organização → Tipos de Solicitação.
  2. Na linha do tipo (ex.: Férias), clique em Editar.
  3. Role até Monte o fluxo etapa a etapa, adicione/remova etapas e configure cada uma (gestor, RH ou usuário específico).
  4. Salve. Novas solicitações desse tipo já usam o fluxo.

O que esta tela faz

  • Listar, filtrar e abrir cadastro/edição dos tipos.
  • Não define etapas aqui — isso é no Editar.

Problemas comuns

Não acho onde montar Etapa 1 / Etapa 2
Clique em Editar no tipo desejado (não use só esta listagem). Consulte o tópico Editar Tipo de Solicitação no menu ao lado.
Sem permissão
Falta ListRequestTypes / UpdateRequestType no nível de acesso.
