RustDesk (TI / Acessos)

Função no sistema

Inventário dos IDs RustDesk das máquinas da empresa, com senha de acesso remoto armazenada de forma criptografada. Serve para a equipe de TI localizar rapidamente um computador e copiar o ID (e, se necessário, a senha) sem deixar o segredo visível na tela. A conexão remota de dentro deste portal ainda não está disponível — use o cliente RustDesk no computador.

O que significam os termos

ID RustDesk
Número exibido no cliente RustDesk da máquina (somente dígitos; espaços na digitação são ignorados).
Senha do RustDesk
Cópia informativa da senha que a máquina já usa. Fica salva só para consulta e cópia no portal (AES-256-GCM); a listagem nunca a mostra. Não serve de login neste sistema.
Senha do usuário
Senha da conta de quem está logado neste Administrativo. É exigida de novo para ver ou copiar a senha da máquina.
Apelido
Nome amigável (ex.: usuario@hostname), como costuma aparecer no painel do RustDesk.

Quem acessa: TiRustdesk (lista), TiRustdeskCreate, TiRustdeskUpdate, TiRustdeskView e TiRustdeskReveal (olho/cópia da senha), no grupo ACL TI - Sistemas e Acessos. A carga em lote usa ainda ImportCenterTi na Central de Importações. Quem já tinha as páginas de Sistemas na data da migration recebe a cópia automática; se o nível foi liberado depois, marque também as páginas RustDesk.

Fluxo principal

  1. Acesse TI / Acessos → RustDesk.
  2. Para carga em lote, use Administração → Importações (tipo TI — RustDesk) ou o botão Importar nesta tela. Baixe o modelo CSV, preencha ID, apelido e, se quiser, senha/colaborador.
  3. Opcionalmente vincule o colaborador dono da máquina e anote observações.
  4. Na grade, o card mostra o apelido da máquina e, abaixo, o colaborador vinculado (se houver). O ícone de cópia ao lado do número copia o ID (sem senha).
  5. O olho pede a senha da sua conta neste sistema e então mostra a senha do RustDesk por 30 segundos. A chave ao lado copia a senha sem exibi-la, também após a mesma confirmação.
  6. Abra o cliente RustDesk, cole o ID e, se precisar, a senha.
  7. Para corrigir dados ou trocar a senha, use a ficha (reticências) e Editar. Deixe o campo senha em branco para manter a atual; marque Remover a senha cadastrada para apagá-la.

Campos e parâmetros

Apelido Obrigatório. Identifica a máquina na grade colorida.
ID RustDesk Obrigatório, único, 6 a 16 dígitos.
Senha do RustDesk Opcional. Só para consulta e cópia no portal (não é login deste sistema). Criptografada em repouso. Nunca entra no log de alterações em claro.
Colaborador Usuário do Administrativo, opcional. Quando vinculado, o nome aparece no card abaixo do apelido.
Status Ativo (aparece no filtro padrão) ou inativo (máquina desligada/desativada).
Observações Texto livre (local, ramal, etc.).

Problemas comuns

Menu RustDesk não aparece
Libere as páginas do grupo TI - Sistemas e Acessos no nível de acesso (em especial TiRustdesk). Execute a migration 20261005180000_create_ti_rustdesk e recarregue a sessão.
Não consigo gravar senha
A aplicação gera a chave em storage/private/secrets/ti_rustdesk.key na primeira gravação (a pasta precisa de escrita). Opcionalmente defina TI_RUSTDESK_ENCRYPTION_KEY no .env. Guarde backup desta chave fora do dump do banco — sem ela as senhas já gravadas não abrem.
Olho pede senha e diz “Senha incorreta”
Use a senha com a qual você entrou neste sistema, não a senha do RustDesk.
Já existe um cadastro com esse ID
O ID é único. Edite o registro existente em vez de cadastrar de novo.
Quero conectar de dentro do Administrativo
Ainda não há cliente embutido. Copie ID/senha e use o aplicativo RustDesk. O acesso direto pelo portal está previsto para uma versão futura.
Quero cadastrar vários de uma vez
Use Administração → Importações, tipo TI — RustDesk, ou o botão Importar nesta tela. Baixe o modelo CSV (rótulos + nomes dos campos). Permissão: ImportCenterTi.
Importação diz “Colaborador não encontrado”
O campo é opcional. A linha é gravada mesmo assim, sem vincular a pessoa. Confira se o login/e-mail existe no cadastro de usuários se quiser o vínculo na ficha.
Página não encontrada
Rode a migration 20261005180000_create_ti_rustdesk. Quem já tinha permissão de Sistemas recebe as páginas RustDesk na mesma migration.
