Sistemas (TI / Acessos)

Função no sistema

Catálogo de sistemas e equipamentos que possuem controle de usuário próprio (incluindo embarcados fora da rede). Serve de base para o mapa colaborador ↔ acesso usado no desligamento. Cada instalação física de um sistema embarcado deve ser um registro separado, identificado pela tag do equipamento e, quando possível, pela filial.

O que significam os termos

Sistema embarcado
Aplicação ou painel instalado em equipamento de chão de fábrica (CLP, IHM etc.), muitas vezes sem rede corporativa permanente.
Tag do equipamento
Identificador da máquina física (ex.: EXT-03, IHM-L1). Permite distinguir o mesmo software em equipamentos diferentes.
Mapa de acessos
Registro de quais colaboradores têm conta/login em cada sistema do catálogo — não é a ACL de páginas deste Portal.

Quem acessa: permissões TiSistemas, TiSistemasCreate, TiSistemasUpdate e TiSistemasView (grupo ACL TI - Sistemas e Acessos).

Fluxo principal

  1. Acesse TI / Acessos → Sistemas.
  2. Clique em Cadastrar. Informe o nome do software, o tipo e a filial.
  3. Se o tipo for embarcado, preencha obrigatoriamente a tag do equipamento (e, se útil, fabricante, modelo e nº de série).
  4. Cadastre uma linha por instalação física (mesmo software em duas máquinas = dois registros).
  5. Abra o sistema e use Liberar acesso para vincular colaboradores.
  6. Na ficha do sistema, acompanhe quem ainda está ativo e marque Inativar após desligar a conta no equipamento.

Campos e parâmetros

Código interno Gerado automaticamente ao cadastrar (sequencial numérico com 5 dígitos, ex.: 00001). Na edição fica somente leitura.
Nome Nome do sistema ou software (obrigatório). Ex.: IHM Siemens.
Tipo embarcado, local, rede, saas ou outro.
Filial Unidade (cadastro de Filiais) onde o sistema/equipamento está instalado.
Localização Área ou linha dentro da filial (ex.: Linha 1, Portaria).
Tag do equipamento Identificação da máquina. Obrigatória para tipo embarcado; única no catálogo.
Fabricante / Modelo / Nº série Detalhes opcionais do equipamento (exibidos quando o tipo é embarcado). O nº de série é texto livre — sem vínculo automático com Patrimônio.
Status Ativo (pode receber novos acessos) ou inativo.
Acessos ativos Contagem de vínculos ainda não revogados.

Problemas comuns

Menu TI / Acessos não aparece
Libere as páginas do grupo TI - Sistemas e Acessos no nível de acesso (páginas nascem sem permissão automática).
Erro ao salvar embarcado sem tag
Para tipo embarcado a tag do equipamento é obrigatória. Use uma tag distinta por máquina.
Tag já cadastrada
A tag precisa ser única. Se o mesmo software existe em outra máquina, cadastre outro registro com outra tag.
Não consigo liberar acesso
O sistema precisa estar com status ativo. Confira também a permissão TiAcessosCreate.
Página não encontrada / campos novos ausentes
Execute as migrations 20260730170000_create_ti_sistemas_acessos e 20260731140000_enrich_ti_sistemas_equipamento.
