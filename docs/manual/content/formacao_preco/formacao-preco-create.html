Cadastrar formação de preço

Função no sistema

Cria um cenário nomeado vazio (ou só com o cabeçalho). Depois o sistema abre a edição para incluir produtos e metas.

O que significam os termos

Alíquotas padrão
ICMS, PIS e COFINS sugeridos em cada linha nova da grade. Podem ser alterados produto a produto.

Quem acessa: FormacaoPrecoCreate. A lista usa FormacaoPreco.

Fluxo principal

  1. Em Precificações, clique em Nova precificação.
  2. Informe o nome (obrigatório) e, se quiser, observação e alíquotas.
  3. Clique em Criar e incluir produtos.
  4. O sistema grava o cenário e abre a tela de edição da grade.

Campos e parâmetros

Nome Até 180 caracteres. Ex.: proposta, linha, data da planilha.
Observação Contexto da negociação.
ICMS / PIS / COFINS padrão % Digite 12,00 para 12%. Padrão Tiaraju: 12,00 / 1,65 / 7,60.

Problemas comuns

Pede o nome
Sem nome o cenário não é gravado.
Alíquota inválida
Use percentual entre 0 e 99,99. Não digite 0,12 para 12% — digite 12 ou 12,00.
