Status dos Treinamentos

Função no sistema

Lista e filtra registros de Status dos Treinamentos no módulo Gestão de Treinamentos. Use esta tela para localizar itens, acessar visualização/edição e iniciar novos cadastros.

Visão geral do módulo: consulte também o tópico Matrizes de treinamentos (rh-trein-matrizes) para o fluxo completo da área.

Quem acessa: usuários com permissão ListTrainingStatus.

Fluxo principal (passo a passo)

  1. Acesse o menu Gestão de Treinamentos e abra Status dos Treinamentos.
  2. Use os filtros no topo para restringir por nome, status ou outros critérios.
  3. Ajuste Mostrar N registros se precisar ver mais linhas por página.
  4. Clique em Visualizar, Editar ou use ações na matriz de realizados conforme sua permissão.
  5. Pressione F1 nesta tela para reabrir esta ajuda contextual.

Campos e parâmetros

O que cada campo afeta no sistema.

Filtros de busca Restringem os registros exibidos na grade; não alteram dados, apenas a consulta.
Mostrar N registros Controla paginação (10, 20, 50 ou 100 por página).
Status exibido Pendente, dentro do prazo, vencido, agendado ou concluído. Registros cancelados na matriz de realizados voltam a aparecer aqui como pendência na versão vigente.

Problemas comuns

Não vejo o menu desta tela
Permissão ListTrainingStatus ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
Treinamento cancelado na matriz não reaparece aqui
Verifique se a versão vigente do treinamento está ativa e se o cancelamento reabriu a pendência na versão correta (consulte completed-trainings-matrix).
