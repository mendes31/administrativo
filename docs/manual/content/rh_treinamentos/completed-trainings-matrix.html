Matriz de Treinamentos Realizados

Consulta consolidada de treinamentos já aplicados aos colaboradores: data de realização, avaliação, nota, instrutor, aproveitamento e exportação. Permite corrigir dados ou cancelar lançamentos incorretos, devolvendo o treinamento ao status pendente quando aplicável.

Visão geral do módulo: consulte também Matrizes de treinamentos (rh-trein-matrizes) e Status dos Treinamentos (list-training-status).

Quem acessa:

  • CompletedTrainingsMatrix — visualizar a matriz, filtrar e exportar.
  • EditCompletedTraining — editar registro realizado (ícone azul).
  • DeleteCompletedTraining — cancelar realização (ícone vermelho).

Fluxo principal (passo a passo)

  1. Acesse Gestão de Treinamentos → Matriz de Treinamentos Realizados.
  2. Use os filtros (colaborador, treinamento, mês, ano, código, aproveitamento) e clique em Filtrar.
  3. Revise os cartões de resumo no topo (totais, média de nota, horas).
  4. Na coluna Ações, use Editar para ajustar dados ou Cancelar para desfazer um lançamento errado.
  5. Exporte para Excel ou PDF, se necessário, mantendo os filtros ativos.
  6. Pressione F1 nesta tela para reabrir esta ajuda.

Editar treinamento realizado

  1. Clique no botão azul Editar na linha desejada.
  2. Altere data de realização, data de avaliação, nota, instrutor ou observações.
  3. Informe a justificativa e confirme com sua senha.
  4. Salve. O registro permanece na matriz de realizados, apenas com os dados corrigidos.

Cancelar treinamento realizado (lançamento incorreto)

Use quando o treinamento foi registrado por engano e deve voltar para Status de Treinamentos como pendente.

  1. Clique no botão vermelho Cancelar na linha desejada.
  2. Leia o aviso do modal (especialmente se o registro for de versão antiga).
  3. Informe a justificativa e confirme com sua senha.
  4. Confirme o cancelamento. O registro some da matriz de realizados.

Regras de cancelamento e versionamento

Versão atual do treinamento
Remove o registro da matriz e reabre a pendência na versão vigente (se o treinamento estiver ativo).
Versão antiga do treinamento
Remove apenas o histórico daquela versão. Não reabre pendência na versão inativa.
Versão antiga com conclusão copiada na versão atual
Cancela o registro antigo e o correspondente na versão atual (mesma data de realização). Reabre pendência na versão vigente, se ativa.
Versão antiga com retreinamento obrigatório na nova versão
Remove o histórico antigo. Se o colaborador não tiver conclusão na versão atual, reabre pendência na versão vigente.
Mais de uma conclusão do mesmo treinamento
Cancelar uma data específica remove só aquele registro. As demais conclusões permanecem.

Campos e parâmetros

O que cada filtro e coluna representa.

Colaborador / Treinamento / Código Restringem a consulta; não alteram dados.
Mês / Ano Filtram pela data de realização.
Aproveitamento Aprovado (nota ≥ 7), Reprovado ou vazio.
Versão Indica a versão do treinamento no momento do lançamento.
Exportar Excel / PDF Gera arquivo com todos os registros do filtro atual (sem paginação da tela).
Justificativa e senha Obrigatórias em edição e cancelamento; ficam registradas em log de alterações.

Problemas comuns

Não vejo os botões Editar ou Cancelar
Além de CompletedTrainingsMatrix, é necessário EditCompletedTraining ou DeleteCompletedTraining no nível de acesso.
Cancelar não faz nada ao clicar
Recarregue a página (Ctrl+F5). Se persistir, verifique erros no console do navegador.
Cancelou mas não voltou para Status de Treinamentos
Pode ser versão antiga sem efeito na vigente, treinamento inativo ou ainda existir outra conclusão do mesmo colaborador/treinamento.
Cancelou versão antiga e sumiu também na versão atual
Comportamento esperado quando a conclusão foi copiada na migração sem retreinamento; a pendência é reaberta na versão vigente.
Erro de senha ou permissão
Confirme a senha do usuário logado e as permissões no pacote de páginas do RH.
Realizado não aparece na matriz
Verifique filtros, código do treinamento ou se o lançamento foi feito em outra versão do mesmo código.
