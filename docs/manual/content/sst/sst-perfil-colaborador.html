Perfil SST do colaborador

Função no sistema

Visão consolidada do histórico ocupacional de um colaborador para consulta rápida pela equipe SST.

Quem acessa: usuários com permissão de perfil SST (SstEmployeeProfile). Acesso pela busca de colaborador, relatório de pendências ou listagens.

O que significam os termos

EPI
Equipamento de Proteção Individual exigido para controlar riscos ocupacionais; no SST inclui fichas e entregas.
ASO
Atestado de Saúde Ocupacional emitido após exame médico do trabalho (admissional, periódico, etc.).
PPP
Perfil Profissiográfico Previdenciário. O gerado neste sistema é rascunho interno, não documento oficial para INSS ou eSocial.

Como abrir o perfil (passo a passo)

  1. Em pendências ou listagens, clique no nome do colaborador, ou
  2. Use a busca de perfil SST (quando disponível no menu ou atalho).
  3. Navegue pelas abas conforme a informação desejada.
  4. Pressione F1 com uma aba ativa para abrir a ajuda na seção correspondente.

Aba Pendências

EPIs, exames e treinamentos críticos ou a vencer. Ponto de partida para tratar o colaborador no dia.

Aba Riscos

Riscos ocupacionais vinculados ao cargo/setor (e GHE, se aplicável). Explique a origem das obrigações.

Aba Obrigatoriedades

Lista consolidada do que o colaborador deve possuir (EPI, exame, treinamento), independente do status. EPIs vêm de cargo (risco/necessidade) e do GHE ativo; o mesmo item aparece uma vez.

Aba Timeline

Linha do tempo de eventos SST: ASOs, entregas, treinamentos, afastamentos — útil para auditoria.

Aba ASOs

Histórico de ASOs e exames. Link para criar novo ASO ou ver detalhe.

Aba Afastamentos

Registros de afastamento com CID e período.

Aba EPIs

Fichas de entrega e situação de assinatura. Link para nova ficha pré-preenchida quando aplicável.

Aba Acidentes

Acidentes e incidentes envolvendo o colaborador.

Aba PPP

PPPs gerados para o colaborador. São rascunho interno (não oficial). O botão gera nova versão com aviso; o PDF leva marca d’água.

Fluxo principal

  1. Abra este tópico pela central de ajuda (F1) ou pelo menu do módulo.
  2. Identifique a área ou tela relacionada ao que precisa fazer.
  3. Siga o link ou o caminho de menu indicado para a tela operacional.
  4. Na tela de destino, use o F1 novamente para o passo a passo detalhado.

Campos e parâmetros

Mapa do módulo Links e resumos das telas cobertas por esta visão geral.
Permissões Cada tela operacional exige a página correspondente no nível de acesso.
Ajuda contextual (F1) Em cada tela de destino, o F1 abre o tópico detalhado daquela função.

Problemas comuns

Perfil vazio de riscos/obrigações
Cargo ou setor não cadastrados no usuário, ou sem vínculo risco ↔ cargo/setor.
Pendência no relatório mas não no perfil
Atualize a página; confira se está no mesmo colaborador e se filtros de status coincidem.
Não encontro o colaborador
Usuário pode estar inativo ou sem permissão para visualizar aquele setor.
