eSocial e PPP

Função no sistema

Fila de rascunhos internos de eventos eSocial (JSON de conferência) e geração de PPP não oficial a partir dos registros SST. Nenhuma destas telas transmite ao governo nem substitui documento previdenciário.

Quem acessa: SST com SstListEsocialEventos, SstViewEsocialEvento, SstGenerateEsocialEvento, SstSyncEsocialPendentes, SstExportEsocialJson, SstMarkEsocialEnviado, SstListPpp, SstViewPpp, SstGeneratePpp, SstExportPppPdf.

O que significam os termos

eSocial
Sistema de escrituração digital do governo. Eventos SST oficiais atuais: S-2210, S-2220, S-2221 e S-2240 (condições ambientais / Tabela 24). Este sistema não envia esses eventos.
S-2240
Condições ambientais do trabalho e agentes nocivos. Não é gerado a partir de entrega de EPI; EPI é só evidência.
S-2245
Evento antigo de treinamentos, fora do desenho oficial atual. A geração está bloqueada.
PPP
Perfil Profissiográfico Previdenciário. O PDF daqui é rascunho interno, não documento para INSS, eSocial ou perícia.

Fluxo principal

  1. Use o módulo SST no dia a dia (acidente, ASO, EPI, treinamento). Isso é a fonte operacional.
  2. Na Fila eSocial, gere só rascunhos S-2210 (CAT) e S-2220 (ASO) para conferir JSON. Não há transmissão.
  3. Exporte JSON se precisar arquivar a conferência. “Registrar conferência” anota protocolo interno — não envia ao governo.
  4. Para PPP, no perfil SST do colaborador use Gerar PPP (não oficial).
  5. O PDF sai com marca d’água “NÃO OFICIAL”. Não entregue como PPP previdenciário.

Fila eSocial

  • Gerar rascunhos S-2210/S-2220 — JSON simplificado (layout S-1.2). Layout alvo futuro: S-1.3.
  • S-2240 e S-2245 — geração bloqueada. Eventos antigos na fila aparecem como legado, sem regenerar.
  • Exportar JSON — download do rascunho.
  • Registrar conferência — observação interna; não é envio ao eSocial.

PPP

Gerar PPP (não oficial) Snapshot interno de exposições, ASOs e EPIs. Campos como eficácia de EPI são placeholders.
Exportar PDF Documento com aviso e marca d’água; não é o PPP oficial.

Campos e parâmetros

Mapa do módulo Fila eSocial, detalhe do evento, listagem e visão do PPP, geração no perfil SST.
Permissões Cada ação exige a página correspondente no nível de acesso (listadas em “Quem acessa”).
Ajuda contextual (F1) Nestas telas o F1 abre este tópico.

Problemas comuns

Botão S-2245 sumiu / geração recusada
Esperado. Treinamento não gera evento eSocial neste módulo. O certificado continua no portal.
S-2240 a partir de EPI recusado
Esperado. S-2240 oficial é condição ambiental, não ficha de entrega.
JSON não é aceito no transmissor
Não use este JSON para envio. Falta XML/XSD, mensageria e layout S-1.3.
PPP incompleto ou recusado no INSS
Este PPP não deve ser enviado ao INSS. Complete avaliações ambientais fora deste rascunho.
