Equipamentos e vistorias

Controle de equipamentos de segurança (extintores, hidrantes, etc.) com checklist e vistorias periódicas.

Quem acessa: SST e responsáveis com SstListEquipamentos, SstCreateEquipamento, SstListEquipamentoTipos, SstRegisterEquipamentoRecarga, SstMinhasEquipamentoVistorias.

Tipos de equipamento

Cadastre cada categoria (Extintor, Hidrante, etc.) antes dos equipamentos. O prefixo define a numeração automática.

Campos do tipo

Nome * Nome exibido nas listas e no cadastro do equipamento (ex.: Extintor).
Código * Identificador interno do tipo (ex.: EXTINTOR). Não é o código do equipamento; serve para organização e busca.
Prefixo * Exatamente 3 caracteres (A–Z / 0–9), únicos no sistema (ex.: EXT, HID). Usado para gerar o código do equipamento (EXT00001).
Controla recarga / validade de carga Marque para tipos que precisam de controle de recarga (ex.: Extintor). Habilita campos de data no equipamento, histórico e alertas. Tipos sem essa necessidade (hidrante, porta, etc.) deixam desmarcado.
Validade padrão (meses) Quando controla recarga: quantidade de meses usada para calcular a próxima data ao registrar uma recarga (padrão 12).
Status Ativo = disponível no cadastro de equipamentos; Inativo = oculto nas novas inclusões.
Descrição Texto livre opcional sobre o tipo.
Checklist Itens de inspeção vinculados ao tipo. Na vistoria, o responsável responde a cada item (conforme / não conforme / N/A).

Novo / editar equipamento — campos

Identificação

Tipo * Selecione primeiro. Define o checklist das vistorias e o prefixo do código. Ex.: Extintor (EXT).
Código * Gerado automaticamente: prefixo do tipo + 5 dígitos (ex.: EXT00001). Na inclusão, a tela mostra uma prévia; o valor definitivo é confirmado ao salvar. Na edição, o código não pode ser alterado.
Patrimônio Número patrimonial da empresa (plaqueta / inventário físico), se houver. Independente do código automático.
Status Ativo = entra na fila de vistorias; Inativo = pausado; Baixado = fora de uso (descarte / substituição).
Localização Onde o equipamento está instalado (setor, sala, torre, etc.). Facilita a vistoria em campo.
Departamento Departamento responsável pela área do equipamento (opcional).
Responsável Usuário que recebe as vistorias na fila “Minhas vistorias”. Se vazio (“fila geral”), qualquer usuário com permissão pode executar conforme a regra do módulo.

Características

Fabricante Marca / fabricante do equipamento.
Modelo Modelo comercial ou referência do fabricante.
Capacidade Capacidade técnica (ex.: 6 kg, 10 L), conforme o tipo.
Nº série Número de série do fabricante.
Data fabricação Data de fabricação informada na etiqueta / documento.

Recarga / validade de carga

Aparece somente se o tipo estiver marcado com “Controla recarga”. Independente das vistorias periódicas.

Data recarga Data da última recarga / serviço de carga no cadastro (resumo atual).
Próxima recarga Calculada automaticamente: data da recarga + validade em meses definida no tipo (ex.: 12). Você pode ajustar manualmente. Na listagem: verde (em dia), amarelo (vence em até 30 dias), vermelho (vencida).
Registrar recarga No detalhe do equipamento: informa data, tipo de evento (Recarga, Teste hidrostático, etc.), empresa e documento. O sistema grava o histórico e atualiza automaticamente a última e a próxima data. Se “Próxima” ficar vazia, calcula data + validade em meses do tipo.
Histórico de recargas Linha do tempo de todas as recargas/manutenções — não se perde ao editar o cadastro.

Vistorias

Periodicidade * Intervalo entre competências (Mensal, Bimestral, Trimestral, Semestral, Anual). Define com que frequência o sistema gera vistorias.
Dia da vistoria Dia do mês em que o cron abre a vistoria e define o prazo. “Padrão do módulo” usa o dia configurado em Configurações de vistorias.
Mês referência (1ª competência) Data âncora da primeira competência. Se vazio, usa a data de cadastro do equipamento.
Gerar vistorias automaticamente Se marcado, o cron / rotina cria as competências. Se desmarcado, a geração automática não inclui este equipamento.
Observações Anotações livres (histórico, restrições de acesso, etc.).

Padrões globais (dia padrão, regras do cron) ficam em Configurações de vistorias.

Código automático (resumo)

  1. Cadastre o tipo com prefixo de 3 caracteres.
  2. No equipamento, escolha o tipo.
  3. O sistema gera PREFIXO + sequência de 5 dígitos (ex.: HID00002).
  4. Novos tipos podem ser criados a qualquer momento, desde que o prefixo seja único.

Fluxo principal (passo a passo)

  1. Cadastre tipos com prefixo e checklist.
  2. Cadastre o equipamento (tipo → código automático → localização e demais dados).
  3. Ajuste periodicidade e, se necessário, as Config. vistorias.
  4. O responsável executa em Minhas vistorias ou via Ler QR.
  5. Itens não conformes podem gerar plano de ação.

Ler QR / painel do equipamento

Cada equipamento tem um QR na ficha. A URL aponta para sst-scan-equipamento/{token}.

  1. Escaneie o QR com o celular (ou use Ler QR dentro do sistema, com a câmera).
  2. Se não estiver logado, o sistema pede login e, ao concluir, volta ao painel do equipamento (não ao dashboard).
  3. O painel mostra dados básicos (código, nº de série, patrimônio, localização), badges de vistoria e recarga (quando o tipo controla) e a lista de pendências.
  4. Se houver vistoria aberta e você for o responsável, use Iniciar vistoria. A ficha completa e o registro de recarga ficam nos atalhos do painel.

Problemas comuns

Recarga vencida na lista
Abra o equipamento e use Registrar recarga com a nova data; a próxima é recalculada automaticamente.
Campos de recarga não aparecem
No tipo do equipamento, marque Controla recarga / validade de carga (ex.: Extintor).
Não consigo salvar o equipamento
Confirme se o tipo tem prefixo de 3 caracteres cadastrado.
Prefixo já existe
Cada tipo precisa de um prefixo único (ex.: EXT, HID).
Código não muda na edição
É intencional: o código é gerado só no cadastro e permanece fixo.
QR cai no dashboard após login
Atualize a página e escaneie de novo; o retorno pós-login deve abrir o painel do equipamento. Se persistir, limpe o cache do navegador e confirme que a URL do QR contém sst-scan-equipamento/ + token.
QR não abre vistoria
Equipamento inativo/baixado, você não é o responsável, ou vistoria já concluída no período. O painel ainda mostra os dados e o status de recarga.
Vistoria vencida no dashboard
Execute a vistoria ou reassigne o responsável.
Checklist vazio
Inclua itens no cadastro do tipo de equipamento.
Não conforme sem ação
Abra plano de correção com prazo.
