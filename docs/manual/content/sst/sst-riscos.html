Riscos ocupacionais

Função no sistema

Catálogo mestre de agentes e situações de risco. A partir do risco derivam exames, EPIs e treinamentos obrigatórios.

O que significam os termos

EPI
Equipamento de Proteção Individual exigido para controlar riscos ocupacionais; no SST inclui fichas e entregas.
ASO
Atestado de Saúde Ocupacional emitido após exame médico do trabalho (admissional, periódico, etc.).
PPP
Perfil Profissiográfico Previdenciário: histórico de exposições e atividades para fins previdenciários/eSocial.

Listagem

Exibe riscos cadastrados com status, grupo e nível. Use filtros e busca para localizar.

Cadastro / edição

Nome Identificação do risco (ex.: Ruído, Poeira mineral).
Grupo / Categoria Classificação para relatórios e PGR.
Nível Gravidade ou prioridade (Baixo, Médio, Alto…).
Status Apenas riscos ativos entram no cálculo de pendências.
Descrição / Medidas Texto livre para documentação e PPP.

Aba Cargos / Setores

Define quem está exposto a este risco. Sem vínculo aqui, exames, EPIs e treinamentos do risco não geram pendências.

  • Cargo + setor — exposição específica (ex.: Gerente de TI no setor TI).
  • Somente setor — todos os cargos daquele departamento.
  • Somente cargo — cargo em qualquer setor.
  • Nível de exposição — registro qualitativo (Baixo, Médio, Alto).

Aba Exames

Exames complementares obrigatórios para expostos a este risco.

Exame Item do catálogo (audiometria, espirometria…).
Categoria ASO Em qual tipo de ASO o exame entra (periódico, admissional…).
Periodicidade Meses entre realizações; sobrescreve o padrão do catálogo se informado.
Obrigatório Se desmarcado, exame é recomendado, não obrigatório.

Aba EPIs

EPIs obrigatórios para neutralizar ou reduzir o risco.

EPI Item do catálogo (protetor auricular, PFF2…).
Validade de troca (meses) Periodicidade de substituição para quem está exposto.
Obrigatório EPI recomendado vs obrigatório.

Aba Treinamentos

Treinamentos de segurança vinculados ao risco.

Treinamento Item do catálogo SST.
Validade (meses) Reciclagem específica para este risco.
Opcional Desmarcado = obrigatório (padrão). Marque apenas se for recomendado.
Dica F1 Com uma aba selecionada na tela do risco, pressione F1 para abrir esta página já posicionada na seção da aba ativa.

Fluxo principal

  1. Abra este tópico pela central de ajuda (F1) ou pelo menu do módulo.
  2. Identifique a área ou tela relacionada ao que precisa fazer.
  3. Siga o link ou o caminho de menu indicado para a tela operacional.
  4. Na tela de destino, use o F1 novamente para o passo a passo detalhado.

Campos e parâmetros

Mapa do módulo Links e resumos das telas cobertas por esta visão geral.
Permissões Cada tela operacional exige a página correspondente no nível de acesso.
Ajuda contextual (F1) Em cada tela de destino, o F1 abre o tópico detalhado daquela função.

Problemas comuns

Não vejo o menu ou a tela
Confirme a permissão da página no nível de acesso e relogue se a migration/menu acabou de ser aplicada.
Não consigo salvar ou a ação não aparece
Falta permissão de criar/editar, ou o registro está em status que bloqueia a operação.
Lista vazia ou sem dados esperados
Revise filtros, período e escopo (filial/departamento); pode não haver registros no critério atual.
F1 abre outro tópico
Use a busca na central de ajuda pelo título Riscos ocupacionais ou o menu do módulo.
