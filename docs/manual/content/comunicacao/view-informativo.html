Visualizar Informativo

Função no sistema

Exibe os dados de um registro de Visualizar Informativo em modo somente leitura, com atalhos para editar ou excluir quando permitido.

Visão geral do módulo: consulte também o tópico Informativos (com-informativos) para o fluxo completo da área.

Quem acessa: usuários com permissão ViewInformativo.

Fluxo principal (passo a passo)

  1. Na listagem, clique em Visualizar no registro desejado.
  2. Revise ID, datas de cadastro/edição e observações.
  3. Use os botões do cabeçalho para ir à listagem, editar ou consultar log de alterações.

Campos e parâmetros

O que cada campo afeta no sistema.

Dados exibidos Espelham o estado atual do registro no banco; use Editar para modificar.
Conteúdo (links) Links inseridos no editor aparecem em azul e sublinhados na visualização e no modal do Dashboard, para ficarem distinguíveis do texto corrido.

Problemas comuns

Não vejo o menu desta tela
Permissão ViewInformativo ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
O link no conteúdo parece texto normal
Atualize a página (CSS em cache). Links válidos do editor devem aparecer em azul e sublinhados; se ainda parecer texto, edite o informativo e reinsira o hiperlink pelo botão de link.
Pressione F1 nesta tela para reabrir esta ajuda contextual
