Criar Evento Corporativo

Função no sistema

Cadastra um novo registro em Criar Evento Corporativo. Preencha os campos obrigatórios e salve; o registro passará a aparecer nas listagens e poderá receber permissões conforme o pacote.

Visão geral do módulo: consulte também o tópico Eventos corporativos (com-eventos) para o fluxo completo da área.

Quem acessa: usuários com permissão CreateCompanyEvent.

Fluxo principal (passo a passo)

  1. Na listagem, clique em Cadastrar (ou acesse diretamente create-company-event).
  2. Preencha todos os campos obrigatórios marcados no formulário.
  3. Revise o impacto de status, vínculos e flags (ativo, público, padrão) antes de salvar.
  4. Confirme o cadastro; o sistema exibirá mensagem de sucesso ou erro de validação.
  5. Volte à listagem e verifique se o novo registro aparece com os filtros corretos.

Campos e parâmetros

O que cada campo afeta no sistema.

Campos do formulário Cada campo do formulário grava um atributo do registro; campos vazios podem impedir o salvamento.
Status / Ativo Só evento ativo entra no sino e dispara a notificação. Se a publicação for futura, o sistema grava como inativo até essa data, no mesmo modelo dos informativos.
Publicar a partir de Vazio publica e notifica na hora (se estiver ativo). Com data futura, sino e push saem somente nesse horário.
Exige confirmação de presença Desmarcado: o aviso fica no sino até o colaborador visualizar o evento. Marcado: fica até confirmar ou recusar. Em ambos, sai ao encerrar o prazo de confirmação (se preenchido) ou a data de fim do evento, mesmo sem visualizar ou responder.
Departamento Vazio divulga a todos. Com departamento, o push vai só para colaboradores daquele departamento. O sino segue a visibilidade do evento no portal.

Problemas comuns

Não vejo o menu desta tela
Permissão CreateCompanyEvent ausente no seu nível de acesso. Solicite inclusão no pacote correto.
Erro 004 ao executar ação
Você tem a listagem, mas não a permissão da ação (criar, editar, excluir). Inclua a página filha no pacote.
Pressione F1 nesta tela para reabrir esta ajuda contextual
