# Catálogo de capacidades

## Finalidade

Registrar o que a plataforma é capaz de fazer, independentemente de telas,
pastas ou tecnologias. O catálogo orienta ownership, diagnóstico e roadmap.

## Estados

- **Operacional:** fluxo utilizável de ponta a ponta;
- **Parcial:** existe, mas possui lacunas relevantes;
- **Estrutural:** há schema ou preparação sem fluxo utilizável;
- **Planejada:** aprovada para roadmap;
- **Não avaliada:** depende de diagnóstico.

## Governança

Cada diagnóstico deve:

1. validar o estado inicial;
2. decompor capacidades amplas;
3. associar proprietário e fontes;
4. identificar dependências;
5. classificar evolução como essencial, recomendada ou avançada;
6. definir indicadores de eficácia.
